# ROS2 · AI · OpenCV 학습 아카이브

ROS 2 개발 환경, 로봇 내비게이션, LLM·모방학습, OpenCV 컴퓨터 비전 실습을 정리한 정적 학습 사이트입니다.

## 웹사이트

[🌐 ROS2 학습 웹사이트 바로가기](https://pjongb.github.io/ROS2/)

## 구성

- 코드 확장 실습 1개
- 개발 환경 강의 6개
- ROS 2 기본기 학습 페이지 8개
- TF2·DDS·모바일 로봇 학습 페이지 15개
- PinkyPro 실습 7개
- LLM 실습 10개
- TurtleBot3 실습 6개
- 모방학습 실습 10개
- TF Listener·RViz2 통합 심화 노트
- OpenCV 개념·이론·행렬 학습 페이지 14개(환경 설정부터 특징 추출·라벨링·외곽선까지)
- OpenCV 강의별 Jupyter Notebook 14개 다운로드
- 무작위 문제은행 385문제

사이트는 GitHub Pages에서 바로 열 수 있으며, OpenCV 개념 페이지에서 원본 강의 HTML·PDF를 열거나 강의별 `.ipynb` 실습 파일을 다운로드할 수 있습니다.
