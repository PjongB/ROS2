Task를 명확히 정의하고, 카메라·관절 Observation과 Leader Action을 에피소드로 수집해 재현 가능한 LeRobotDataset을 만듭니다.

품질의 출발점하나의 완전한 시연이 Episode이며, 같은 Task를 여러 위치에서 일관된 방식으로 반복 수집합니다.
01

Task · Episode · 정책 흐름

  • Task: “Pick up Doll and put in cup”처럼 동작·대상·목적지가 분명한 목표입니다.
  • Episode: Task 시작부터 성공 종료까지의 한 번의 완전한 시연입니다.
  • Observation: Follower의 6-DOF state와 front/wrist 등의 RGB 이미지입니다.
  • Action: 사람이 움직인 Leader 관절값이며 학습 후 Policy가 예측할 목표입니다.

Teleoperation → (Observation, Action) 기록 → Policy 학습 → 새 Observation에서 Action 예측 순서로 이어집니다.

02

meta/info.json에서 format version, robot type, episode/frame 수, FPS, feature names와 Parquet·video 경로를 확인할 수 있습니다.

03

좋은 시연을 만드는 기준

  • 실제 녹화 전에 최소 10~20회 원격 조종을 연습합니다.
  • 위치당 약 10개, 전체 최소 50개 에피소드부터 시작하고 복잡하면 100개 이상 수집합니다.
  • 완전한 실패는 제외하고, 실패 후 복구해 성공한 에피소드는 목적에 맞게 포함할 수 있습니다.
  • 카메라와 조명을 고정하고 사람·Leader arm·불필요한 움직임이 영상에 들어오지 않게 합니다.
  • 작업 영역과 중요 물체가 모든 frame에서 보이도록 640×480·30 FPS 이상을 기준으로 잡습니다.
다양성과 일관성의 균형: 물체 위치는 필요한 범위 안에서 바꾸되, 배경·카메라·조명·그릇 위치처럼 Task와 무관한 조건은 통제합니다.
04

카메라와 Task 이름 규칙

좋은 이름피할 이름
front, top, wristlaptop, phone
wrist.left, wrist.top장치 모델명·임시 번호

수집·학습·평가에서 같은 카메라 key와 robot/teleop ID를 유지합니다. Task 문장은 동사로 시작하고 대상과 목적지를 포함해 모든 에피소드에서 동일하게 사용합니다.

05

100개 에피소드 수집

source ~/venv/il/bin/activate
HF_USER=$(hf auth whoami | head -n 1 | sed 's/\x1b\[[0-9;]*m//g' | awk -F': ' '{print $2}' | xargs)

cd ~/il_ws/src/lerobot
lerobot-record \
  --robot.type=omx_follower \
  --robot.port=/dev/omx_follower \
  --robot.id=omx_follower_arm \
  --robot.cameras="{front: {type: opencv, index_or_path: 0, width: 640, height: 480, fps: 30}, wrist: {type: opencv, index_or_path: 2, width: 640, height: 480, fps: 30}}" \
  --teleop.type=omx_leader \
  --teleop.port=/dev/omx_leader \
  --teleop.id=omx_leader_arm \
  --display_data=true \
  --dataset.repo_id=${HF_USER}/pick_and_place \
  --dataset.single_task="Pick up Doll and put in cup" \
  --dataset.episode_time_s=30 \
  --dataset.num_episodes=100 \
  --dataset.reset_time_s=10
실행 전: 같은 로봇을 제어하는 이전 프로세스를 모두 종료하고, Follower 가동 범위와 비상 정지 방법을 확인합니다. 카메라 번호는 v4l2-ctl --list-devices 결과에 맞춥니다.
06

녹화 중 제어

키동작
오른쪽 화살표현재 에피소드 종료 후 다음으로 이동
왼쪽 화살표현재 에피소드 취소 후 다시 녹화
Esc세션 종료 후 데이터셋 업로드

Recording → Reset → Recording을 반복합니다. --resume=true로 추가 수집할 때 num_episodes는 최종 총수가 아니라 이번에 더 녹화할 개수입니다.

07

로컬 저장과 수동 업로드

로컬 데이터는 ~/.cache/huggingface/lerobot/{repo-id}에 저장됩니다.

huggingface-cli upload \
  ${HF_USER}/record-test \
  ~/.cache/huggingface/lerobot/${HF_USER}/record-test \
  --repo-type dataset

Hub에서 Dataset Viewer와 meta/info.json을 열어 episode 수, FPS, 카메라 key와 robot type을 검증합니다.
