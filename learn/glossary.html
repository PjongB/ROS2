ROS

ROS 2 기본

Node · 노드

센서 처리, 제어, 지도 제공처럼 하나의 역할을 수행하는 실행 단위입니다.

Topic · 토픽

Publisher가 계속 발행하고 Subscriber가 받아보는 비동기 데이터 통로입니다.

Publisher / Subscriber

토픽에 메시지를 보내는 쪽과 그 메시지를 구독해 처리하는 쪽입니다.

Service · 서비스

요청 하나에 응답 하나를 돌려주는 통신입니다. 짧은 작업에 적합합니다.

Action · 액션

오래 걸리는 목표를 보내고 진행 피드백·결과·취소를 처리하는 통신입니다. Nav2 Goal도 액션으로 처리됩니다.

Message · 메시지

토픽·서비스·액션에서 교환하는 데이터 형식입니다. 예: Twist, PoseStamped, LaserScan.

Parameter · 파라미터

노드의 동작을 바꾸는 설정값입니다. RQt, YAML, ros2 param으로 확인하거나 변경합니다.

Launch

여러 노드와 파라미터를 한 번에 실행하는 구성 파일 또는 실행 과정입니다.

Package · 패키지

노드, 설정, launch, 리소스와 의존성을 기능별로 묶은 ROS 2 프로젝트 단위입니다.

Workspace / Colcon

여러 패키지를 개발하는 작업 공간과 이를 빌드하는 도구입니다. 빌드 후 install 환경을 source해야 합니다.

DDS / Domain ID

DDS는 ROS 2 통신 기반이며 Domain ID가 같은 프로세스끼리 기본적으로 서로 발견하고 통신합니다.

QoS

메시지 신뢰성, 보관 수, 내구성 등을 정하는 통신 품질 규칙입니다. 양쪽 설정이 맞지 않으면 연결되지 않을 수 있습니다.

TF

TF·로봇 모델

TF / Transform

두 좌표계 사이의 이동과 회전 관계입니다. 로봇 각 부품과 지도 속 자세를 연결합니다.

Frame · 프레임

위치와 방향을 표현하는 기준 좌표계입니다. 좌표값은 어느 frame 기준인지 함께 알아야 의미가 있습니다.

map

지도에 고정된 전역 좌표계입니다. AMCL이 map → odom을 보정합니다.

odom

바퀴 odometry를 기준으로 연속적인 이동을 표현하는 좌표계입니다. 부드럽지만 시간이 지나면 오차가 누적됩니다.

base_footprint

바닥에 투영된 로봇 중심 좌표계입니다. 2D 내비게이션의 로봇 자세 기준으로 자주 사용합니다.

base_link

로봇 본체의 기준 링크입니다. 높이를 포함할 수 있어 base_footprint와 구분됩니다.

Quaternion / Yaw

Quaternion은 3D 회전을 안정적으로 표현하는 네 값이며, yaw는 2D 평면에서 Z축을 중심으로 도는 방향각입니다.

URDF / Xacro

URDF는 링크·조인트·형상을 기술하는 로봇 모델이고, Xacro는 반복과 변수를 사용할 수 있게 확장한 작성 방식입니다.

Link / Joint

Link는 로봇의 강체 부품이고 Joint는 두 Link가 연결되고 움직이는 관계입니다.

Odometry

바퀴 회전과 속도 등을 적분해 로봇의 상대 이동을 추정한 값입니다. 미끄러짐 때문에 장기 오차가 생깁니다.

SENSE

센서·시뮬레이션

LaserScan / /scan

2D 라이다가 각 방향에서 측정한 장애물 거리 배열입니다. RViz의 점과 costmap 장애물의 근거가 됩니다.

LiDAR · 라이다

레이저를 쏘고 돌아오는 시간을 이용해 주변 물체까지 거리를 측정하는 센서입니다.

/cmd_vel / Twist

로봇에 전달하는 목표 선속도와 각속도입니다. 보통 linear.x와 angular.z를 사용합니다.

Gazebo

로봇, 센서, 물리 환경을 가상으로 실행하는 시뮬레이터입니다.

Bridge

Gazebo Transport와 ROS 2 토픽 사이에서 메시지 형식을 변환해 전달합니다.

use_sim_time

시스템 시간이 아니라 Gazebo의 /clock을 사용하게 하는 설정입니다. 시뮬레이션 노드들이 같은 시간을 써야 합니다.

MAP

SLAM·위치 추정

SLAM

로봇의 위치를 추정하면서 동시에 주변 지도를 만드는 기술입니다.

Occupancy Grid

공간을 격자로 나눠 각 칸을 비어 있음, 점유됨, 알 수 없음으로 표현한 지도입니다.

PGM / YAML

PGM은 지도 이미지이고 YAML은 해상도, 원점, 임계값과 이미지 경로를 저장합니다.

Localization

이미 만들어진 지도 안에서 현재 로봇의 위치와 방향을 찾는 과정입니다.

AMCL

LaserScan, 지도, odometry를 비교하고 파티클 필터로 지도 속 로봇 자세를 추정합니다.

Particle · 파티클

로봇이 있을 가능성이 있는 자세 후보입니다. 센서와 잘 맞는 후보의 확률이 높아집니다.

2D Pose Estimate

AMCL에 초기 위치와 방향을 알려주는 RViz 도구입니다. 지도를 회전시키는 기능이 아닙니다.

NAV2

Nav2 구조

Nav2 Goal

도착할 위치와 최종 방향을 지정하는 목표 자세입니다.

Planner Server

현재 위치부터 목표까지 Global Plan을 계산하는 planner 플러그인을 실행합니다.

Controller Server

Global Plan을 따라가도록 Local Controller를 실행하고 /cmd_vel을 계산합니다.

Global Plan

전체 지도에서 목적지까지 어느 길로 갈지 나타내는 장거리 경로입니다.

Local Plan

Global Plan을 따라가기 위해 지금 로봇 주변에서 선택하는 짧은 실제 주행 궤적입니다.

BT Navigator

계획, 경로 추종, 재계획, 복구 순서를 Behavior Tree로 관리합니다.

Behavior Tree · BT

조건과 행동 노드를 트리로 연결해 내비게이션 실행 순서와 실패 대응을 표현합니다.

Lifecycle Node

unconfigured, inactive, active 같은 상태를 거쳐 시작·정지되는 관리형 노드입니다.

Recovery / Behavior

로봇이 막혔을 때 대기, 회전, 후진, costmap 초기화, 재계획 등을 수행하는 복구 행동입니다.

PATH

경로 탐색 알고리즘

A*

현재까지의 이동 비용과 목표까지의 예상 비용을 더해 목적지 방향을 우선 탐색하는 Global Planner 알고리즘입니다.

Dijkstra · 다익스트라

시작점에서 누적 비용이 작은 곳부터 넓게 탐색해 최단 경로를 찾습니다. 목표 방향 휴리스틱을 사용하지 않습니다.

D*

환경이나 비용이 바뀌었을 때 기존 탐색 결과를 활용해 경로를 효율적으로 다시 계산하는 계열입니다. Dijkstra와 다른 알고리즘입니다.

NavFn

Nav2의 격자 기반 planner 플러그인으로 A* 또는 Dijkstra를 사용해 경로를 만들 수 있습니다.

Smac Planner

2D A*, Hybrid-A*, State Lattice 등을 제공하며 로봇 형태와 운동 제약을 더 자세히 고려할 수 있는 planner 계열입니다.

Heuristic · 휴리스틱

A*가 현재 칸에서 목표까지 남은 비용을 추정하는 값입니다. 탐색 방향과 속도를 개선합니다.

DRIVE

Local Controller

DWA

현재 낼 수 있는 여러 선속도·각속도 조합으로 미래 궤적을 예측하고 가장 좋은 속도를 선택하는 Dynamic Window Approach입니다.

DWB

DWA 기반 후보 궤적을 장애물, 경로 정렬, 목표 거리, 진동 등의 Critic으로 평가하는 Nav2 Local Controller입니다.

Critic

DWB에서 후보 궤적에 점수를 매기는 평가 기준입니다. 예: PathAlign, GoalDist, BaseObstacle.

RPP

Global Plan 앞쪽의 lookahead point를 추종하고 곡률·장애물에 따라 속도를 조절하는 Regulated Pure Pursuit Controller입니다.

Lookahead Point

경로 추종 시 로봇이 당장 향할 Global Plan 위의 앞쪽 기준점입니다.

Trajectory · 궤적

특정 속도 명령을 적용했을 때 로봇이 앞으로 지나갈 것으로 예측되는 위치와 방향의 연속입니다.

COST

Costmap·튜닝

Costmap

공간을 이동 가능 여부뿐 아니라 위험 비용으로 표현한 격자 지도입니다.

Global Costmap

전체 지도에서 Global Plan을 계산하는 데 쓰는 장거리 비용 지도입니다.

Local Costmap

로봇 주변 센서 정보를 갱신하며 Local Controller가 충돌과 회피를 판단하는 비용 지도입니다.

Inflation Layer

장애물 주변에 거리에 따른 위험 비용을 퍼뜨려 경로가 벽에 너무 붙지 않게 하는 계층입니다.

inflation_radius

장애물 비용이 퍼지는 최대 범위입니다. 높이면 안전 영역이 넓어지고 좁은 통로는 줄어듭니다.

cost_scaling_factor

거리 증가에 따라 비용이 감소하는 속도입니다. 높이면 비용이 더 빨리 떨어져 벽 가까운 경로를 허용하기 쉬워집니다.

Footprint / Padding

Footprint는 충돌 검사에 사용하는 로봇 외곽선이고 padding은 그 외곽에 추가하는 안전 여유입니다.

Lethal Obstacle

로봇이 통과하면 충돌한다고 판단하는 최고 위험 비용의 장애물 영역입니다.

PID

PID·제어 응답

P · 비례 제어

현재 오차가 클수록 큰 출력을 냅니다. 너무 크면 overshoot와 진동이 증가합니다.

I · 적분 제어

오래 남은 오차를 누적해 정상상태 오차를 제거합니다. 과하면 wind-up이 생깁니다.

D · 미분 제어

오차 변화 속도를 보고 미리 제동해 overshoot와 진동을 줄입니다. 센서 노이즈에 민감합니다.

Overshoot

응답이 목표를 지나쳐 반대편으로 벗어난 크기입니다.

Steady-state Error

충분한 시간이 지난 뒤에도 목표와 현재값 사이에 남는 정상상태 오차입니다.

Wind-up

로봇이 움직이지 못하거나 출력이 포화된 동안 I 항이 계속 누적돼 나중에 과도한 출력을 만드는 현상입니다.

Tolerance · 허용 오차

완벽한 0 대신 이 범위 안이면 목표에 도달했다고 판단하는 기준입니다.

Saturation · 출력 포화

계산 출력이 커져도 모터 또는 설정된 최대 명령 이상으로 낼 수 없는 상태입니다.
