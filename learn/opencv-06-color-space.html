이론과 수식

addWeighted는 크기가 같은 두 영상의 대응 원소를 선형 결합합니다. 워터마크는 ROI에서 배경을 마스크로 비우고 전경을 OR/ADD하여 합성합니다.

dst(x,y) = α·src1(x,y) + β·src2(x,y) + γ mask=0 → 차단, mask=255 → 통과 result = background ∨ foreground

행렬로 보기

RGBαααR′G′B′
채널별 동일한 가중 합성 연산

함수 사용법

강의에서 사용하는 핵심 함수의 호출 형태와 인자·반환값을 함께 정리했습니다. 긴 코드는 가로로 스크롤해서 볼 수 있습니다.

함수·표현호출 예인자·반환값과 사용 포인트
cvtColorhsv = cv2.cvtColor(bgr, cv2.COLOR_BGR2HSV)입력 배열과 변환 코드를 받아 새 색 공간 영상을 반환합니다. 변환 방향에 맞는 코드를 사용해야 합니다.
addWeighteddst = cv2.addWeighted(a, alpha, b, beta, gamma)같은 크기·자료형의 두 영상을 alpha·beta 비율로 합하고 gamma를 더한 포화 연산 결과를 반환합니다.
bitwise_anddst = cv2.bitwise_and(src1, src2, mask=mask)대응 비트를 AND하며 선택적 mask가 0이 아닌 위치만 결과에 반영합니다.
bitwise_notinverse = cv2.bitwise_not(mask)각 비트를 반전합니다. 0/255 이진 마스크에서는 선택 영역과 배경이 서로 바뀝니다.

from pathlib import Path
import cv2
import numpy as np
import matplotlib.pyplot as plt

def read_rgb(path):
    image = cv2.imread(str(path))
    if image is None:
        raise FileNotFoundError(path)
    return cv2.cvtColor(image, cv2.COLOR_BGR2RGB)

STEP 04

ROI와 마스크로 워터마크 합성

base = image.copy()
logo = read_rgb(Path("data/watermark_no_copy.png"))
logo = cv2.resize(logo, (min(320, base.shape[1] // 3), min(180, base.shape[0] // 3)))

y0 = base.shape[0] - logo.shape[0]
x0 = base.shape[1] - logo.shape[1]
roi = base[y0:, x0:]

gray = cv2.cvtColor(logo, cv2.COLOR_RGB2GRAY)
_, mask = cv2.threshold(gray, 245, 255, cv2.THRESH_BINARY_INV)
background = cv2.bitwise_and(roi, roi, mask=cv2.bitwise_not(mask))
foreground = cv2.bitwise_and(logo, logo, mask=mask)
base[y0:, x0:] = cv2.add(background, foreground)

plt.imshow(base)
plt.axis("off");
