TurtleBot3 Navigation

저장한 지도에서 AMCL 초기 위치를 설정하고 목표점·좌표·다중 Waypoint 주행을 실행합니다.

핵심Nav2 주행 전에 2D Pose Estimate로 지도 속 로봇 위치와 방향을 실제 로봇에 맞춰야 합니다.
01

Bringup과 Navigation

SBC에서 bringup, PC에서 저장한 지도 YAML을 지정해 Navigation을 실행합니다. 지도 파일 경로는 절대경로가 안전합니다.

02

AMCL 초기 위치

  • RViz의 2D Pose Estimate를 선택합니다.
  • 실제 위치에서 화살표를 실제 진행 방향으로 드래그합니다.
  • LiDAR scan과 지도 벽이 어긋나면 다시 지정하고 잠시 움직여 수렴시킵니다.
03

Nav2 Goal

목적지 위치뿐 아니라 도착 후 바라볼 방향도 화살표로 설정합니다. 전역 경로와 지역 costmap이 나타난 뒤 장애물을 피해 주행합니다.

04

현재 위치와 지도 좌표

ros2 topic echo /amcl_pose
ros2 topic echo /clicked_point

Publish Point로 지도를 클릭하면 /clicked_point에서 해당 좌표를 확인할 수 있습니다.

05

다중 Waypoint

RViz의 Waypoint 모드에서 Nav2 Goal 방식으로 여러 점을 순서대로 추가하고 Start Waypoint Following을 실행합니다.

터미널에 입력하는 전체 실행 순서

# 터미널 A - PC에서 SBC 접속 후 bringup
ssh <username>@<robot-ip>
source /opt/ros/jazzy/setup.bash
source ~/turtlebot3_ws/install/setup.bash
ros2 launch turtlebot3_bringup robot.launch.py

# 터미널 B - PC에서 저장 지도 기반 Navigation
source /opt/ros/jazzy/setup.bash
source ~/turtlebot3_ws/install/setup.bash
export ROS_DOMAIN_ID=30
export TURTLEBOT3_MODEL=burger
ls -lh $HOME/turtlemap.yaml $HOME/turtlemap.pgm
ros2 launch turtlebot3_navigation2 navigation2.launch.py \
  map:=$HOME/turtlemap.yaml

# 터미널 C - 현재 위치 확인
ros2 topic echo /amcl_pose

# 터미널 D - RViz Publish Point 좌표 확인
ros2 topic echo /clicked_point
  1. RViz에서 2D Pose Estimate를 먼저 지정합니다.
  2. 지도와 LiDAR가 일치합니다.
  3. 경로가 생성되고 안전하게 목표에 도착합니다.
  4. Waypoint를 지정한 순서로 방문합니다.
FIX

문제 해결

  • scan과 지도가 어긋남: 2D Pose Estimate를 실제 위치·방향에 맞게 다시 지정합니다.
  • 경로 생성 실패: 목표가 지도 자유 공간에 있는지, global costmap과 planner 상태를 확인합니다.
  • 로봇이 움직이지 않음: Nav2 lifecycle 상태, controller와 /cmd_vel을 확인합니다.
  • 장애물 앞에서 멈춤: local costmap의 obstacle·inflation layer와 회피 공간을 확인합니다.
  • 목표 방향이 이상함: Nav2 Goal 화살표의 끝 방향이 도착 후 orientation입니다.
