PinkyPro로 맵 작성하기

MAP

실제 로봇 SLAM 데이터 흐름

센서와 TF → SLAM → 지도

LiDAR /scan ───────────┐
Encoder odometry ──────┼→ SLAM Toolbox → /map + map → odom
odom → base_footprint ─┘                      ↓
teleop → cmd_vel → 로봇 이동              RViz 확인
                                               ↓
                                      map_saver_cli
  • 필수 입력: LaserScan, odometry, odom → base_footprint TF가 필요합니다.
  • SLAM 출력: occupancy grid map과 map → odom 보정 TF를 제공합니다.
  • 운전자 역할: 공간을 중복 탐색해 scan matching과 loop closure를 돕습니다.
01

지도 그릴 준비

로봇 2개·PC 2개 터미널

  • 로봇과 PC가 같은 네트워크와 ROS 도메인에 있는지 확인합니다.
  • LiDAR의 /scan, odometry와 TF가 정상인지 먼저 점검합니다.
  • 실습 공간의 장애물과 낙하 위험을 제거합니다.
01

터미널 4개를 역할별로 분리

로봇 2개 + PC 2개

  • 로봇 1: 센서·모터·odometry·TF bringup
  • 로봇 2: SLAM Toolbox와 지도 생성
  • PC 1: RViz의 Map·LaserScan·TF 확인
  • PC 2: teleop 저속 주행
02

bringup·SLAM·RViz 실행

실제 로봇 실행 흐름

  • 로봇에서 bringup을 시작해 센서와 구동부를 올립니다.
  • 별도 로봇 터미널에서 map_building launch를 실행합니다.
  • PC에서 map_view를 열어 Map·LaserScan·TF를 확인합니다.
03

RViz에서 정상 상태 판단

Fixed Frame: map

  • LaserScan 점이 실제 벽과 지도 벽에 일치하는지 확인합니다.
  • 로봇 모델이 지도 위에서 이동 방향과 같은 방향으로 움직여야 합니다.
  • 맵이 겹치거나 순간 이동하면 주행을 멈추고 TF·odometry·scan 정렬을 확인합니다.
03

천천히 주행하며 지도 그리기

teleop 실습

  • teleop_twist_keyboard를 실행해 저속으로 공간의 외곽부터 주행합니다.
  • 급회전을 피하고 이미 지나간 위치를 다시 방문해 loop closure를 돕습니다.
  • RViz에서 벽이 겹치거나 지도가 비틀리지 않는지 계속 확인합니다.
05

완성된 지도 저장

map_saver_cli

  • map_saver_cli -f my_map으로 지도 이미지와 YAML을 함께 저장합니다.
  • my_map.pgm과 my_map.yaml이 생성됐는지 확인합니다.
  • 두 파일을 같은 폴더에 보관해 Localization에서 재사용합니다.
06

PGM과 YAML의 역할

지도 픽셀과 실제 좌표 연결

  • PGM: 흰색은 이동 공간, 검정은 장애물, 회색은 미확인 영역입니다.
  • resolution: 이미지 한 픽셀이 실제 몇 m인지 나타냅니다.
  • origin: 이미지 기준점의 map 좌표 x, y, yaw입니다.
  • threshold: 픽셀을 장애물 또는 빈 공간으로 판단하는 기준입니다.
07

좋은 지도를 만드는 법

위치 추정이 쉬운 지도

  • 비슷한 구조가 반복되면 위치를 혼동하므로 구분되는 특징을 확보합니다.
  • 고속 주행과 급회전은 scan matching 오차를 키우므로 천천히 움직입니다.
  • 이미 지나간 곳을 다시 방문해 loop closure가 일어나게 합니다.
  • 평평한 바닥에서 작성하고 필요하면 작은 노이즈와 빈틈을 정리합니다.
08

증상별 문제 해결

입력 → TF → 주행 → 저장 순서

  • 지도가 안 보임: /map, /scan, Fixed Frame과 SLAM 로그를 확인합니다.
  • 벽이 두 겹임: 회전 속도, odometry, LaserScan frame과 시간 동기화를 확인합니다.
  • 위치가 점프함: TF 끊김, 센서 지연과 반복되는 환경 특징을 확인합니다.
  • 저장 파일이 없음: 현재 디렉터리 권한과 map saver 응답을 확인합니다.

마지막 실행 순서

# 로봇 1 — bringup
ros2 launch pinky_bringup bringup_robot.launch.xml

# 로봇 2 — SLAM
ros2 launch pinky_navigation map_building.launch.xml

# PC 1 — RViz
ros2 launch pinky_navigation map_view.launch.xml

# PC 또는 로봇 — 주행
ros2 run teleop_twist_keyboard teleop_twist_keyboard

# 지도 저장
ros2 run nav2_map_server map_saver_cli -f my_map

실습 체크리스트

  1. /scan과 odometry·TF가 정상입니다.
  2. RViz Fixed Frame은 map이고 LaserScan이 벽과 일치합니다.
  3. 낮은 속도로 외곽과 내부를 중복 탐색했습니다.
  4. 지도에 심한 겹침, 비틀림과 끊긴 벽이 없습니다.
  5. my_map.pgm과 my_map.yaml을 함께 저장했습니다.
