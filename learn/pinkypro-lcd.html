PinkyPro LCD 사용하기

PinkyPro LCD 예제를 준비하고 Pillow 이미지·텍스트·한글 폰트·GIF와 Picamera 영상을 화면에 출력하는 과정을 익힙니다.

01

예제 파일 준비

  1. 제공된 LCD example 압축 파일을 다운로드합니다.
  2. 다운로드 위치를 확인하고 압축을 풉니다.
  3. home 위치로 pinky_lcd 폴더를 옮깁니다.
  4. 예제 스크립트와 이미지 파일을 확인합니다.
02

LCD 하드웨어 테스트

cd ~/pinky_lcd
python3 lcd_test.py

화면 전체가 밝게 출력되면 기본 통신과 전원 상태를 확인한 것입니다.

03

이미지 출력

from pinky_lcd import LCD
from PIL import Image
import time

lcd = LCD()
img = Image.open("example.jpg")
lcd.img_show(img)
time.sleep(3)
lcd.close()

작업 디렉터리를 기준으로 이미지 경로가 맞는지 확인하고 사용 후 장치를 닫습니다.

04

텍스트를 중앙에 출력

  • Image.new로 320×240 RGB 배경을 만듭니다.
  • ImageDraw.Draw로 그리기 객체를 생성합니다.
  • textbbox로 글자 크기를 구해 중앙 x·y를 계산합니다.
  • draw.text로 그린 뒤 LCD에 보냅니다.
bbox = draw.textbbox((0, 0), text, font=font)
text_width = bbox[2] - bbox[0]
text_height = bbox[3] - bbox[1]
x = (320 - text_width) // 2
y = (240 - text_height) // 2
05

한글 폰트와 밝기

  • 기본 폰트는 한글에 제한이 있어 TTF 폰트를 로봇으로 복사합니다.
  • ImageFont.truetype에 파일 경로와 크기를 지정합니다.
  • lcd.set_backlight(1~100)으로 밝기를 설정합니다.
lcd.set_backlight(50)
font = ImageFont.truetype("MaruBuri-Bold.ttf", 30)
06

GIF 프레임 재생

img = Image.open("example.gif")
for frame in ImageSequence.Iterator(img):
    lcd.img_show(frame.rotate(180))
lcd.close()

GIF는 여러 frame의 모음입니다. 필요하면 각 frame의 duration을 sleep 간격에 반영합니다.

07

Picamera 실시간 출력

picam2 = Picamera2()
picam2.configure(picam2.create_preview_configuration(
    main={"format": "RGB888", "size": (640, 480)}))
picam2.start()

while True:
    frame = picam2.capture_array()
    rgb = cv2.cvtColor(frame, cv2.COLOR_BGR2RGB)
    rotated = cv2.rotate(rgb, cv2.ROTATE_180)
    flipped = cv2.flip(rotated, 1)
    lcd.img_show(Image.fromarray(flipped))

무한 루프는 KeyboardInterrupt를 처리하고 finally에서 camera와 LCD를 닫는 것이 안전합니다.

08

증상별 확인

  • 검은 화면: backlight, 전원과 테스트 스크립트를 확인합니다.
  • 이미지 없음: 현재 디렉터리와 파일 경로를 확인합니다.
  • 한글 깨짐: TTF 위치와 truetype 경로를 확인합니다.
  • 색상이 이상함: OpenCV BGR과 Pillow RGB 변환을 확인합니다.
  • 방향 반대: rotate 각도와 flip 축을 조정합니다.
