04.04 · PINKYPRO · NAV2 실제 주행

PinkyPro로 Nav2 주행하기

저장한 지도를 로드하고 AMCL 초기 위치를 맞춘 뒤 단일 목표, 좌표 확인과 여러 Waypoint 주행까지 Nav2의 실제 운용 순서를 익힙니다.

한 줄 정리로봇 bringup → 저장 지도 기반 Nav2 → PC RViz → 2D Pose Estimate → Nav2 Goal 순서로 실행해야 지도와 실제 로봇이 일치한 상태에서 주행할 수 있습니다.
MAP

Nav2 주행 데이터 흐름

저장 Map + /scan + odometry
          ↓
     AMCL 현재 위치
          ↓
Nav2 Goal → Planner → Controller → cmd_vel → PinkyPro
  • Map Server: 저장한 YAML과 지도 이미지를 제공합니다.
  • AMCL: 지도와 LaserScan을 비교해 현재 자세를 추정합니다.
  • Planner·Controller: 목표까지 경로를 만들고 주행 명령을 계산합니다.
BASE

시작 전 준비

  • 04.03에서 만든 YAML과 지도 이미지가 같은 폴더에 있어야 합니다.
  • PC와 로봇의 네트워크·ROS_DOMAIN_ID가 같아야 합니다.
  • 로봇의 실제 시작 위치가 지도 안에서 어디인지 확인합니다.
01

로봇 Bringup

ros2 launch pinky_bringup bringup_robot.launch.xml

LiDAR, odometry, TF와 구동부가 정상인지 먼저 확인합니다.

02

저장 지도로 Navigation 실행

ros2 launch pinky_navigation bringup_launch.xml map:=/home/pinky/my_map.yaml
  • 상대 경로보다 절대 경로를 쓰면 실행 위치에 따른 오류를 줄일 수 있습니다.
  • Map Server, AMCL, Planner, Controller와 lifecycle 상태가 active인지 확인합니다.
03

PC에서 Nav2 RViz 실행

ros2 launch pinky_navigation nav2_view.launch.xml

Map, LaserScan, ParticleCloud, Global/Local Costmap과 RobotModel을 구분해서 확인합니다.

04

2D Pose Estimate로 초기 위치 정렬

  1. 지도에서 로봇의 실제 위치를 클릭합니다.
  2. 실제 로봇이 바라보는 방향으로 드래그합니다.
  3. LaserScan과 지도 벽이 겹치고 AMCL 파티클이 모이는지 확인합니다.
05

Nav2 Goal 보내기

  1. 도착 위치를 클릭합니다.
  2. 도착 후 바라볼 방향으로 드래그합니다.
  3. Global Plan과 Local Costmap을 확인하며 주행을 관찰합니다.
06

지도와 로봇 좌표 확인

# RViz Publish Point로 클릭한 지도 좌표
ros2 topic echo /clicked_point

# AMCL이 추정한 로봇 자세
ros2 topic echo /amcl_pose

clicked_point는 사용자가 고른 지도 좌표이고 amcl_pose는 로봇의 현재 추정 자세입니다.

07

여러 Waypoint 순차 주행

  1. Waypoint 도구를 선택합니다.
  2. 위치와 방향을 하나씩 추가합니다.
  3. 순서와 장애물 여유 공간을 확인합니다.
  4. Start Waypoint Following으로 지정 순서대로 주행합니다.
08

증상별 확인

  • 지도와 scan 불일치: 초기 자세와 TF를 확인합니다.
  • 경로가 없음: 목표 셀, Global Costmap과 footprint를 확인합니다.
  • 경로는 있지만 정지: Local Costmap과 controller를 확인합니다.
  • 다른 방향으로 회전: 초기·목표 yaw 드래그 방향을 확인합니다.

마지막 실행 순서

# 로봇 1
ros2 launch pinky_bringup bringup_robot.launch.xml

# 로봇 2
ros2 launch pinky_navigation bringup_launch.xml map:=/home/pinky/my_map.yaml

# PC
ros2 launch pinky_navigation nav2_view.launch.xml

# 좌표 관찰
ros2 topic echo /clicked_point
ros2 topic echo /amcl_pose

실습 체크리스트

  1. Nav2 lifecycle 노드가 active입니다.
  2. Map과 LaserScan이 겹칩니다.
  3. 단일 Goal 주행을 완료했습니다.
  4. clicked_point와 amcl_pose를 구분합니다.
  5. 여러 Waypoint를 순서대로 주행했습니다.
