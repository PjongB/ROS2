03

Responses API 기본 호출

from openai import OpenAI

client = OpenAI()
MODEL_NAME = "강의에서_사용할_모델"

response = client.responses.create(
    model=MODEL_NAME,
    input="로봇을 처음 배우는 학생에게 ROS 2를 한 문장으로 설명해줘.",
)
print(response.output_text)

모델 이름은 계정에서 사용 가능한 현재 모델로 지정합니다.

04

좋은 prompt 구조

  • 목적: 무엇을 만들 것인가
  • 대상: 초등학생·고등학생·개발자

  • 길이: 문장 수·항목 수
  • 조건: 반드시 포함하거나 금지할 내용
05

자연어를 robot command로 변환

user_command = "앞으로 천천히 가다가 장애물이 보이면 멈춰."

prompt = f"""다음 말을 로봇 제어 명령으로 해석해줘.
사용자 말: {user_command}
출력 형식:
동작:
속도:
정지 조건:
주의사항:"""

생성 결과를 곧바로 모터에 보내지 않고 허용 동작·속도 상한·센서 정지 조건을 별도 코드로 검증합니다.

06

로컬 이미지와 VLM

import base64
from pathlib import Path

image_bytes = Path("my_robot.jpg").read_bytes()
base64_image = base64.b64encode(image_bytes).decode("utf-8")

response = client.responses.create(
    model=MODEL_NAME,
    input=[{"role":"user","content":[
        {"type":"input_text","text":"로봇 부품과 위험 요소를 설명해줘."},
        {"type":"input_image","image_url":f"data:image/jpeg;base64,{base64_image}"}
    ]}]
)

접근 권한이 없는 image URL은 모델이 가져올 수 없습니다. Base64는 암호화가 아니라 전송용 인코딩입니다.

07

JSON 결과 검증

import json

try:
    data = json.loads(response.output_text)
    risks = data.get("safety_risks", [])
except json.JSONDecodeError:
    data = None

JSON만 출력하도록 지시해도 parsing 실패는 발생할 수 있습니다. 필수 key·type·허용값을 검사하고 실패 시 안전한 기본 동작을 사용합니다.

08

문제 해결

  • 401: Key 누락·폐기·project 권한 확인
  • 429: rate limit·quota·billing 확인
  • 모델 오류: 계정에서 사용 가능한 model name 확인
  • 이미지 실패: MIME type·Base64·URL 접근 권한 확인
  • JSON 실패: raw text 보관 후 parser와 schema validation 적용
