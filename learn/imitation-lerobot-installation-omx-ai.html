LeRobot Installation - OMX-AI

Ubuntu에서 Python 3.10 전용 가상환경을 만들고 LeRobot v0.4.4와 DYNAMIXEL 의존성을 재현 가능한 방식으로 설치합니다.

강의 고정 환경Linux + Python 3.10 + LeRobot v0.4.4 + DYNAMIXEL extras. 최신 main이 아니라 강의와 같은 태그를 사용해야 결과를 재현하기 쉽습니다.

01

Python 3.10 설치

sudo add-apt-repository ppa:deadsnakes/ppa -y
sudo apt update
sudo apt install python3.10 python3.10-venv python3.10-dev -y
  • python3.10: Interpreter
  • python3.10-venv: 프로젝트별 가상환경 생성
  • python3.10-dev: C/C++ 확장 모듈 빌드용 header
python3.10 --version

출력에 Python 3.10.x가 보이면 다음 단계로 이동합니다.

02

LeRobot 전용 가상환경

mkdir -p ~/venv
python3.10 -m venv ~/venv/il
source ~/venv/il/bin/activate
python --version
which python
pip install --upgrade pip
  • Prompt 앞에 (il)이 표시되어야 합니다.
  • which python 결과는 ~/venv/il/bin/python 경로여야 합니다.
  • 가상환경을 끝낼 때는 deactivate를 입력합니다.
03

Imitation Learning Workspace 생성

mkdir -p ~/il_ws/src
cd ~/il_ws/src
pwd

il_ws는 Imitation Learning Workspace이고 src에는 clone한 source를 보관합니다. ROS workspace와 비슷한 디렉터리 습관이지만 이 단계에서는 colcon build를 실행하지 않습니다.

04

LeRobot v0.4.4 가져오기

cd ~/il_ws/src
git clone --branch v0.4.4 https://github.com/huggingface/lerobot.git
cd ~/il_ws/src/lerobot
git describe --tags --always

--branch v0.4.4는 특정 tag의 코드를 checkout해 main branch 변화로부터 강의 환경을 고정합니다.

05

Editable + DYNAMIXEL 설치

# (il) 가상환경이 활성화된 터미널
cd ~/il_ws/src/lerobot
pip install -e ".[dynamixel]"

# 시스템 영상·버전 관리 도구
sudo apt install ffmpeg git -y
구문의미왜 사용하는가
-eEditable modeclone 폴더의 코드 수정이 재설치 없이 반영
.현재 폴더의 Python packageLeRobot source를 설치
[dynamixel]선택 의존성 그룹dynamixel-sdk 등 모터 통신 package 포함
ffmpeg영상 codec·변환 도구카메라 영상 기록·dataset decode
06

설치 검증

source ~/venv/il/bin/activate
python -c "import lerobot; print(lerobot.__version__)"
python -c "import dynamixel_sdk; print('dynamixel-sdk OK')"
ffmpeg -version | head -n 1
pip show lerobot
성공 기준: LeRobot import와 version 출력, dynamixel-sdk OK, ffmpeg version이 모두 확인됩니다.

터미널에 입력하는 전체 순서

# 1. Python 3.10
sudo add-apt-repository ppa:deadsnakes/ppa -y
sudo apt update
sudo apt install python3.10 python3.10-venv python3.10-dev -y

# 2. 전용 가상환경
mkdir -p ~/venv
python3.10 -m venv ~/venv/il
source ~/venv/il/bin/activate

# 3. LeRobot v0.4.4
mkdir -p ~/il_ws/src
cd ~/il_ws/src
git clone --branch v0.4.4 https://github.com/huggingface/lerobot.git
cd ~/il_ws/src/lerobot

# 4. 영상·Git 도구

# 5. 설치 확인
