목차사전 점검실행 구조지도 작성저장명령
한 줄 정리SBC의 센서·모터 bringup과 PC의 Cartographer·teleop을 분리해 실행하며, 양쪽 통신이 확인된 뒤 움직입니다.
SAFE

사전 점검

  • 배터리, LiDAR 회전, OpenCR USB, 주행 공간과 낙하 위험을 확인합니다.
  • PC와 SBC의 네트워크·ROS_DOMAIN_ID·TURTLEBOT3_MODEL을 맞춥니다.
  • PC에서 ros2 topic list로 /scan, /odom, /cmd_vel을 확인합니다.
01

SBC와 PC 실행

SBC에서 로봇 bringup을 먼저 시작하고, PC에서 Cartographer를 실행한 뒤 별도 터미널의 teleop으로 움직입니다.

02

좋은 지도 만들기

  • 처음에는 천천히 회전해 주변 벽을 인식시킵니다.
  • 복도와 방의 경계를 겹쳐 지나가 loop closure를 돕습니다.
  • 급가속·바퀴 미끄러짐·사람이 LiDAR 앞을 막는 상황을 줄입니다.
03

지도 저장과 확인

완성 후 Map Saver로 저장하고 map.yaml의 이미지 경로, 해상도, origin과 map.pgm 존재 여부를 확인합니다.

터미널에 입력하는 전체 실행 순서

# 터미널 A - PC에서 SBC 접속 후 로봇 실행
ssh <username>@<robot-ip>
source /opt/ros/jazzy/setup.bash
source ~/turtlebot3_ws/install/setup.bash
echo $TURTLEBOT3_MODEL
ros2 launch turtlebot3_bringup robot.launch.py

# 터미널 B - PC에서 통신 확인 후 SLAM
source /opt/ros/jazzy/setup.bash
source ~/turtlebot3_ws/install/setup.bash
export ROS_DOMAIN_ID=30
export TURTLEBOT3_MODEL=burger
ros2 topic list
ros2 topic hz /scan
ros2 launch turtlebot3_cartographer cartographer.launch.py

# 터미널 C - PC 키보드 조작
source ~/turtlebot3_ws/install/setup.bash
export TURTLEBOT3_MODEL=burger
ros2 run turtlebot3_teleop teleop_keyboard

# 터미널 D - PC 지도 저장
ros2 run nav2_map_server map_saver_cli -f $HOME/turtlemap
ls -lh $HOME/turtlemap.pgm $HOME/turtlemap.yaml
  1. RViz의 지도와 scan이 안정적으로 겹칩니다.
  2. 미탐색 구역과 심하게 휘어진 벽이 없습니다.
  3. PGM·YAML 두 파일이 저장됐습니다.
FIX

문제 해결

  • PC에서 토픽이 안 보임: PC·SBC의 Domain ID, Wi-Fi와 ROS setup을 확인합니다.
  • scan이 없음: LDS 모델과 bringup 로그, LiDAR 회전을 확인합니다.
  • 지도가 겹침: 속도를 낮추고 충돌·미끄러짐을 피하면서 이미 본 구역으로 돌아옵니다.
  • 지도 저장 실패: 저장 경로의 쓰기 권한과 nav2_map_server 설치를 확인합니다.
