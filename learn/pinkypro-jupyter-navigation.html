04.05 · PINKYPRO · JUPYTER NAVIGATION

Jupyter로 내비게이션

RViz에서 검증한 Nav2 환경을 Jupyter Notebook과 Python API로 제어해 목표 생성, 피드백 확인, 결과 판정과 다중 Waypoint 주행을 실습합니다.

한 줄 정리ROS 2 환경을 source한 터미널에서 Jupyter를 시작해야 Notebook이 Nav2 패키지와 현재 DDS 도메인을 그대로 사용할 수 있습니다.
MAP

Notebook 제어 흐름

Jupyter Kernel → Navigator → Nav2 Action
                              ├─ Feedback
                              └─ Result
                                   ↓
                                PinkyPro

Notebook은 실행 중인 Nav2 시스템에 Action goal을 보내는 클라이언트입니다. 먼저 04.04의 수동 RViz 주행이 정상이어야 합니다.

01

Jupyter 설치

pip3 install jupyter --break-system-packages

PEP 668 정책 때문에 전역 설치에는 옵션이 필요합니다. 재현성과 시스템 보호가 중요하면 가상환경을 우선 고려합니다.

02

Nav2 시스템 먼저 실행

# 로봇
ros2 launch pinky_bringup bringup_robot.launch.xml
ros2 launch pinky_navigation bringup_launch.xml map:=/home/pinky/my_map.yaml

# PC
ros2 launch pinky_navigation nav2_view.launch.xml

2D Pose Estimate로 LaserScan과 지도를 맞추고 Nav2가 active인지 확인합니다.

03

ROS 환경에서 Notebook 시작

source /opt/ros/jazzy/setup.bash
source ~/pinky_/install/local_setup.bash
echo $ROS_DOMAIN_ID
jupyter notebook

커널이 오래된 환경을 사용하면 Kernel Restart 후 import부터 다시 실행합니다.

04

Nav2 클래스와 active 확인

  • 강의에서 제공한 Nav2 클래스를 불러옵니다.
  • Navigator는 goal 전송, feedback·result 조회와 task 취소를 담당합니다.
  • Nav2가 active가 되기 전에 goal을 보내지 않습니다.
05

좌표와 방향 만들기

yaw_rad = math.radians(yaw_degree)
qz = math.sin(yaw_rad / 2.0)
qw = math.cos(yaw_rad / 2.0)
  • goal frame은 일반적으로 map을 사용합니다.
  • x·y는 지도 좌표이고 quaternion은 도착 방향입니다.
  • 현재 위치는 /amcl_pose, 지도 좌표는 /clicked_point로 확인합니다.
06

단일 Goal: 회전 후 이동

  1. 현재 x·y와 다른 yaw로 goal을 만들어 제자리 회전을 확인합니다.
  2. 새 x·y와 yaw로 위치 이동을 확인합니다.
  3. goal 전송 직후 결과를 가정하지 말고 task 완료까지 기다립니다.
07

피드백과 주행 결과

  • 주행 중 feedback에서 남은 거리와 예상 시간을 확인합니다.
  • CPU 부하와 Notebook 멈춤을 줄이기 위해 timeout을 둡니다.
  • 강의처럼 1초 간격으로 확인하면 과도한 polling을 줄일 수 있습니다.
  • 완료 후 성공, 취소, 실패를 구분합니다.
08

여러 좌표 Waypoint 주행

  1. ros2 topic echo /clicked_point를 실행합니다.
  2. RViz Publish Point로 좌표를 순서대로 기록합니다.
  3. z는 무시하고 x·y와 yaw로 pose 목록을 만듭니다.
  4. 주행을 시작하고 feedback으로 진행 지점을 확인합니다.
09

안전하게 종료

  • 진행 중인 task가 있다면 취소 후 최종 상태를 확인합니다.
  • Navigator 노드와 ROS context를 종료합니다.
  • Notebook kernel과 bringup·Nav2 터미널을 순서대로 종료합니다.

실습별 실행 순서

# 1. 로봇 bringup
ros2 launch pinky_bringup bringup_robot.launch.xml

# 2. Nav2 + 저장 지도
ros2 launch pinky_navigation bringup_launch.xml map:=/home/pinky/my_map.yaml

# 3. PC RViz + 초기 위치
ros2 launch pinky_navigation nav2_view.launch.xml

# 4. ROS 환경을 source한 PC 터미널
jupyter notebook

# 5. 좌표 수집
ros2 topic echo /clicked_point
ros2 topic echo /amcl_pose

실습 체크리스트

  1. ROS 환경에서 Jupyter를 실행했습니다.
  2. Nav2 active 확인 후 goal을 보냈습니다.
  3. 회전과 위치 이동을 확인했습니다.
  4. feedback과 result를 구분했습니다.
  5. 여러 Waypoint를 주행했습니다.
  6. task와 노드를 안전하게 종료했습니다.
