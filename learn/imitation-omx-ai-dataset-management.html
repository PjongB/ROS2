데이터셋 관리 - OMX-AI

수집한 에피소드를 영상·관절 그래프로 검토하고, LeRobot 도구로 삭제·분할·병합·feature 제거를 안전하게 수행합니다.

강의 PDF편집 명령 ↓
목차웹 시각화로봇 재생품질 점검에피소드 삭제분할병합Feature 제거
운영 원칙원본은 보존하고 --new_repo_id로 편집본을 만든 뒤, 에피소드 수와 feature schema를 다시 검증합니다.
01

Hub에서 데이터 시각화

LeRobot Dataset Visualizer에 username/dataset-name을 넣으면 별도 로컬 설정 없이 에피소드 영상과 그래프를 확인할 수 있습니다.

  • 전체 sample/frame, episode 수와 FPS
  • 카메라 view와 Language Instruction
  • observation.state와 action 관절 그래프
  • episode 전환·재생·일시정지
02

Follower에서 에피소드 재생

실물 재생 주의: 기록된 궤적대로 Follower가 움직입니다. 수집 때와 비슷한 환경을 만들고 가동 범위를 비운 뒤 낮은 위험의 에피소드부터 확인합니다.
source ~/venv/il/bin/activate
HF_USER=$(hf auth whoami | head -n 1 | sed 's/\x1b\[[0-9;]*m//g' | awk -F': ' '{print $2}' | xargs)

cd ~/il_ws/src/lerobot
lerobot-replay \
  --robot.type=omx_follower \
  --robot.port=/dev/omx_follower \
  --robot.id=omx_follower_arm \
  --dataset.repo_id=${HF_USER}/record-test \
  --dataset.episode=0
03

품질 체크리스트

  • Task가 중간에 끊기지 않고 성공으로 끝났는가
  • 영상과 관절값 사이 frame drop·시간 어긋남이 없는가
  • 중요 물체가 모든 카메라 FOV 안에 있는가
  • 관절 graph에 의도하지 않은 spike가 없는가
  • Task instruction, camera key, FPS와 robot type이 일관적인가
04

낮은 품질의 에피소드 삭제

lerobot-edit-dataset \
  --repo_id ${HF_USER}/record-test \
  --new_repo_id ${HF_USER}/record-test-clean \
  --operation.type delete_episodes \
  --operation.episode_indices "[0, 2, 3]"
권장: 처음에는 --new_repo_id를 반드시 지정합니다. 편집본을 검증한 후에만 후속 학습에 사용하세요.
05

Train · Validation · Test 분할

lerobot-edit-dataset \
  --repo_id ${HF_USER}/record-test-clean \
  --operation.type split \
  --operation.splits '{"train": 0.8, "val": 0.1, "test": 0.1}'
PDF 예시 정정: 강의 PDF의 0.8 + 0.2 + 0.2는 합이 1.2입니다. 비율 분할은 합이 1.0이 되도록 위처럼 사용합니다.

특정 episode를 Task별로 의도적으로 묶을 수도 있습니다.

--operation.splits '{"task1": [0, 1, 2, 3], "task2": [4, 5]}'
06

데이터셋 병합

lerobot-edit-dataset \
  --repo_id ${HF_USER}/merged-dataset \
  --operation.type merge \
  --operation.repo_ids "['${HF_USER}/dataset-a', '${HF_USER}/dataset-b']"

두 데이터셋의 robot type, 관절 차원, camera key, 해상도와 data type 등 feature schema가 같아야 합니다. 에피소드는 repo_ids에 적은 순서로 이어집니다.

07

불필요한 feature 제거

lerobot-edit-dataset \
  --repo_id ${HF_USER}/record-test-clean \
  --new_repo_id ${HF_USER}/record-test-front-only \
  --operation.type remove_feature \
  --operation.feature_names "['observation.images.top']"

사용하지 않는 카메라·센서를 제거해 저장 공간과 입력 구성을 줄일 수 있습니다. 제거 후 학습·평가의 입력 schema도 같은 feature 집합을 사용해야 합니다.

✓

편집 후 검증

  • 원본 repo가 그대로 남아 있습니다.
  • episode 수와 index가 기대한 값입니다.
  • meta/info.json의 feature와 실제 video·Parquet가 일치합니다.
  • Visualizer에서 대표 episode를 다시 재생했습니다.
  • 학습용 split에 평가 episode가 섞이지 않았습니다.
