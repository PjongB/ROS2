한 줄 정리Ollama는 로컬 LLM을 공통 명령과 API로 실행·관리하며, 양자화 모델로 메모리 사용량을 낮춰 개인 PC 실습을 쉽게 만듭니다.
01

로컬 LLM과 Ollama

  • 모델을 내 장비에서 실행하므로 입력 데이터가 외부 API로 전달되지 않습니다.
  • 모델 다운로드·실행·삭제와 API 제공을 하나의 도구로 처리합니다.
  • 속도와 품질은 GPU VRAM, RAM, 모델 크기, 양자화 수준에 좌우됩니다.
02

Linux 설치

curl -fsSL https://ollama.com/install.sh | sh
ollama --version

스크립트를 실행하기 전 Ollama 공식 설치 페이지에서 현재 명령을 확인합니다.

03

기본 모델 관리

ollama run <model_name>
ollama pull <model_name>
ollama list
ollama rm <model_name>

run은 필요하면 모델을 내려받아 대화를 시작하고, 종료할 때는 /bye를 입력합니다.

04

한국어·대형 모델 선택

ollama run hf.co/Bllossom/llama-3.2-Korean-Bllossom-3B-gguf-Q4_K_M:Q4_K_M
ollama run llama3.3:70b-instruct-q2_K

강의 예시에는 3B 한국어 모델과 70B 양자화 모델이 나옵니다. 모델 파일 크기만 보지 말고 실제 VRAM/RAM 사용량과 응답 속도를 확인합니다.

05

GGUF와 Modelfile

  • FROM: 기반 GGUF 또는 모델 지정
  • PARAMETER: temperature 등 생성 옵션
  • SYSTEM: 모델의 기본 역할
  • TEMPLATE: 사용자·assistant message 형식
ollama create llama3.2-Korean -f Modelfile
ollama list
ollama run llama3.2-Korean
06

Python에서 호출

python -m pip install langchain-community langchain langchain-ollama ollama
import ollama

ollama.pull("model_name")
response = ollama.chat(
    model="model_name",
    messages=[{"role": "user", "content": "ROS 2를 설명해줘"}],
)
print(response["message"]["content"])
07

소형 모델 비교 평가

강의는 dataclass에 모델명·prompt·응답·응답시간·성공 여부를 저장하고, 동일 prompt를 순차 실행하는 benchmark 구조를 사용합니다.

  • 코딩·기술 개념, 번역, 요약 등 같은 과제를 사용합니다.
  • 실패와 timeout도 결과로 기록합니다.
  • temperature와 prompt 조건을 고정해야 비교가 의미 있습니다.
  • Orchestrator가 작업에 맞는 모델을 선택하도록 확장할 수 있습니다.
08

소형 모델 활용

  • 회의록 요약
  • 자유 형식 text를 JSON으로 변환
  • 일정·작업 계획을 Markdown으로 정리

구조화 결과는 반드시 JSON parsing과 schema 검증을 거친 뒤 robot command나 외부 시스템에 전달합니다.

09

문제 해결

  • 응답이 매우 느림: 모델 크기·양자화·GPU 사용 여부 확인
  • 메모리 부족: 더 작은 parameter 또는 강한 양자화 모델 사용
  • 한국어 품질 부족: 한국어 fine-tuning 모델과 SYSTEM prompt 비교
  • Python 연결 실패: Ollama service와 모델 이름 확인
  • JSON 파싱 실패: 출력 규칙 강화 후 parser에서 예외 처리

실행 순서

ollama --version
ollama pull <model_name>
ollama run <model_name>
ollama list

# Python 환경
python3 -m venv .venv
source .venv/bin/activate
python -m pip install ollama langchain-ollama

체크리스트

  1. 내 장비에 맞는 모델 크기를 선택했습니다.
  2. run·pull·list·rm의 차이를 설명할 수 있습니다.
  3. Modelfile로 사용자 모델을 생성했습니다.
  4. Python에서 응답과 시간을 기록했습니다.
  5. 구조화 출력의 parsing 실패를 처리했습니다.
