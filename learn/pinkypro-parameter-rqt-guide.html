01

PinkyPro 실행과 관찰 순서

# 터미널 A · 로봇 또는 SSH
source /opt/ros/jazzy/setup.bash
source ~/pinky_/install/local_setup.bash
ros2 launch pinky_bringup bringup_robot.launch.xml

# 터미널 B · 저장 지도 기반 Nav2
source /opt/ros/jazzy/setup.bash
source ~/pinky_/install/local_setup.bash
ros2 launch pinky_navigation bringup_launch.xml \
  map:=/home/pinky/my_map.yaml

# 터미널 C · PC의 RViz
source /opt/ros/jazzy/setup.bash
source ~/pinky_/install/local_setup.bash
ros2 launch pinky_navigation nav2_view.launch.xml

# 터미널 D · 실제 노드 확인
ros2 node list
ros2 param list /controller_server
ros2 param list /local_costmap/local_costmap
ros2 param list /global_costmap/global_costmap
ros2 param list /amcl

노드 이름이 다르면 예문의 이름을 억지로 쓰지 말고 ros2 node list 결과로 바꿉니다.

02

RQT에서 변경하는 순서

source /opt/ros/jazzy/setup.bash
source ~/pinky_/install/local_setup.bash
rqt
  1. Plugins → Configuration → Dynamic Reconfigure를 엽니다.
  2. 대상 노드를 고르고 현재값을 기록합니다.
  3. 한 값만 작게 변경합니다.
  4. CLI로 실제 적용값을 재조회합니다.
  5. RViz의 Path·Costmap·Scan과 실물 움직임을 함께 비교합니다.
ros2 param get /local_costmap/local_costmap \
  inflation_layer.inflation_radius

05

백업과 영구 반영

mkdir -p ~/robot_param_backup
ros2 param dump /controller_server \
  --output-dir ~/robot_param_backup
ros2 param dump /local_costmap/local_costmap \
  --output-dir ~/robot_param_backup
ros2 pkg prefix --share pinky_navigation

RQT 변경은 대부분 재시작하면 사라집니다. 검증된 값만 실제 launch가 읽는 PinkyPro YAML의 올바른 plugin namespace에 반영합니다.

✓

완료 체크리스트

  1. Map·Scan·TF가 먼저 정상입니다.
  2. 변경 전 값을 저장했습니다.
  3. 한 번에 한 항목만 바꿨습니다.
  4. ros2 param get으로 적용값을 확인했습니다.
  5. 검증된 값만 YAML에 반영했습니다.
