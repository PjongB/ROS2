03

openai_client.py

load_dotenv()
client = OpenAI(api_key=os.getenv("OPENAI_API_KEY"))
EMOTIONS = ["angry","basic","bored","fun",
            "happy","hello","interest","sad"]

System prompt는 오직 JSON으로 답하고, assistant_message와 허용된 emotion을 반환하도록 요구합니다. 강의 예제는 Chat Completions API와 gpt-4.1-mini를 사용합니다.

res = client.chat.completions.create(
    model="gpt-4.1-mini",
    messages=msgs,
    temperature=0.4,
)
raw = res.choices[0].message.content

try:
    data = json.loads(raw)
    reply = data["assistant_message"]
    emotion = data["emotion"]
except (json.JSONDecodeError, KeyError, TypeError):
    reply, emotion = raw, "basic"

if emotion not in EMOTIONS:
    emotion = "basic"

실제 model name은 계정에서 사용할 수 있는 현재 모델로 바꿀 수 있습니다.

04

app.py route

from flask import Flask, render_template, request, jsonify

app = Flask(__name__)
history = []

@app.get("/")
def index():
    return render_template("index.html")

@app.post("/chat")
def chat():
    user_text = (request.get_json() or {}).get("text", "").strip()
    if not user_text:
        return jsonify({"error": "text is required"}), 400

    reply, emotion, updated = ask_gpt(user_text, history)
    history[:] = updated
    run_emotion(emotion)
    return jsonify({"reply": reply, "emotion": emotion})

공용 global history는 여러 사용자의 대화가 섞일 수 있습니다. 실제 service에서는 session별 저장소와 history 길이 제한을 사용합니다.

05

index.html의 sendMsg()

async function sendMsg() {
  const input = document.getElementById("user-input");
  const text = input.value.trim();
  if (!text) return;

  addMessage("user", text);
  const res = await fetch("/chat", {
    method: "POST",
    headers: {"Content-Type": "application/json"},
    body: JSON.stringify({text})
  });
  const data = await res.json();
  addMessage("bot", data.reply, data.emotion);
}
XSS 주의: 강의 화면처럼 사용자 입력을 template literal과 innerHTML로 직접 넣지 않습니다. DOM element를 만들고 textContent로 넣어 HTML을 실행하지 못하게 합니다.
06

안전·보안 경계

  • .env는 .gitignore에 넣고 노출된 Key는 즉시 폐기합니다.
  • Flask development server를 Internet에 직접 공개하지 않습니다.
  • 입력 길이·request rate·timeout을 제한합니다.
  • GPT emotion은 allowlist로 검증하고 실패 시 basic을 사용합니다.
  • LLM이 직접 motor speed를 정하지 않게 하고 controller에서 상한을 강제합니다.
  • API 오류·browser disconnect·종료 시 motor stop, LED clear, LCD close를 실행합니다.
07

문제 해결

  • 페이지가 안 열림: Flask 주소·port·robot IP·firewall 확인
  • POST 400: JSON header와 text field 확인
  • API 인증 오류: Key·project·quota 확인
  • JSON parsing 실패: raw response 기록, fallback 적용
  • 감정은 나오지만 robot이 정지: allowlist·hardware log 확인
  • 여러 사용자 history 혼합: session별 history로 분리
