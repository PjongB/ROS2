TurtleBot3 개발 환경 구축

ROS 2 Jazzy PC에 Cartographer·Nav2·Gazebo와 ROBOTIS 패키지를 설치하고 첫 시뮬레이션 주행까지 확인합니다.

MAP

학습 목표

  • TurtleBot3 Burger/Waffle Pi와 PC 개발 환경의 역할을 구분합니다.
  • ROS 2 Jazzy용 ROBOTIS 패키지를 소스 빌드합니다.
  • Gazebo에서 로봇을 띄우고 키보드로 움직입니다.
01

필수 패키지

Cartographer는 지도 작성, Nav2는 위치 추정과 경로 주행, colcon은 ROS 워크스페이스 빌드에 사용합니다.

sudo apt install ros-jazzy-cartographer ros-jazzy-cartographer-ros -y
sudo apt install ros-jazzy-navigation2 ros-jazzy-nav2-bringup -y
sudo apt install python3-colcon-common-extensions -y
02

워크스페이스 구성

jazzy 브랜치의 SDK·메시지·본체·시뮬레이션 저장소를 같은 src 아래에 둡니다. rosdep은 반드시 워크스페이스 루트에서 실행합니다.

03

모델 환경변수

export TURTLEBOT3_MODEL=burger
echo $TURTLEBOT3_MODEL

~/.bashrc에 추가하기 전 기존 항목을 검색하면 중복 설정을 피할 수 있습니다.

04

Gazebo와 teleop 검증

  • 첫 터미널에서 빈 Gazebo 월드를 실행합니다.
  • 두 번째 터미널에서 teleop을 실행합니다.
  • 로봇이 전진·회전·정지하고 터미널 오류가 없는지 확인합니다.

터미널에 입력하는 전체 실행 순서

# 터미널 1 - 설치와 빌드
mkdir -p ~/turtlebot3_ws/src
cd ~/turtlebot3_ws/src
git clone -b jazzy https://github.com/ROBOTIS-GIT/DynamixelSDK.git
git clone -b jazzy https://github.com/ROBOTIS-GIT/turtlebot3_msgs.git
git clone -b jazzy https://github.com/ROBOTIS-GIT/turtlebot3.git
git clone -b jazzy https://github.com/ROBOTIS-GIT/turtlebot3_simulations.git

cd ~/turtlebot3_ws
rosdep update
rosdep install --from-paths src --ignore-src -r -y
colcon build --symlink-install
source ~/turtlebot3_ws/install/setup.bash
export TURTLEBOT3_MODEL=burger

# 터미널 1 - Gazebo 실행
ros2 launch turtlebot3_gazebo empty_world.launch.py

# 터미널 2 - 새 터미널에서 다시 환경 적용 후 teleop
source /opt/ros/jazzy/setup.bash
source ~/turtlebot3_ws/install/setup.bash
export TURTLEBOT3_MODEL=burger
ros2 run turtlebot3_teleop teleop_keyboard

완료 체크

  1. 빌드가 오류 없이 끝납니다.
  2. 모델 환경변수가 burger로 출력됩니다.
  3. Gazebo에 로봇 모델이 나타납니다.
  4. 키보드 명령으로 이동하고 정지합니다.
FIX

문제 해결

  • clone 시 branch 오류: 저장소의 jazzy 브랜치 존재 여부와 철자를 확인합니다.
  • rosdep 오류: 워크스페이스 루트에서 실행했는지, 패키지 목록이 업데이트됐는지 확인합니다.
  • 빌드 실패: 가장 처음 발생한 error부터 해결한 뒤 colcon build --symlink-install을 다시 실행합니다.
  • launch 패키지를 못 찾음: source ~/turtlebot3_ws/install/setup.bash가 적용됐는지 봅니다.
  • 모델이 안 보임: TURTLEBOT3_MODEL 값과 Gazebo 프로세스를 확인합니다.
