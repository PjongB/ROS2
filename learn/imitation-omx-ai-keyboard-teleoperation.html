  3. LeRobot v0.4.4가 설치된 ~/venv/il 가상환경을 사용합니다.

01

Follower 키보드 제어

강의에서 제공하는 omx_f_keyboard_teleop.py를 내려받아 작업 공간으로 옮깁니다. 이 스크립트는 모방학습 데이터를 모으기 전 Follower의 관절 방향과 그리퍼 동작을 빠르게 확인하는 용도입니다.

mv ~/Downloads/omx_f_keyboard_teleop.py ~/il_ws/src/
source ~/venv/il/bin/activate
cd ~/il_ws/src
ls -l /dev/omx_follower
python3 omx_f_keyboard_teleop.py

고정 별칭이 없으면 실제 포트를 찾은 뒤 명시합니다.

lerobot-find-port
python3 omx_f_keyboard_teleop.py --port /dev/ttyACM1
포트 번호 주의: /dev/ttyACM1은 예시입니다. 현재 장비에서 찾은 값을 사용하고, 가능하면 04 강의의 udev 고정 별칭을 먼저 복구하세요.

03

LeRobot Leader-Follower 원격 조종

사람이 Leader를 손으로 움직이면 관절 위치가 Follower로 전달됩니다. 키보드보다 자연스러운 다관절 동작을 만들 수 있어 모방학습 시연의 기본 입력 방식으로 사용합니다.

source ~/venv/il/bin/activate
cd ~/il_ws/src/lerobot

lerobot-teleoperate \
  --robot.type=omx_follower \
  --robot.port=/dev/omx_follower \
  --robot.id=omx_follower_arm \
  --teleop.type=omx_leader \
  --teleop.port=/dev/omx_leader \
  --teleop.id=omx_leader_arm
  • robot.*은 실제 작업을 수행하는 Follower 설정입니다.
  • teleop.*은 사람이 움직이는 Leader 설정입니다.
  • id는 장치를 구분하고 이후 데이터 기록에도 사용하므로 강의 기준 이름을 일관되게 유지합니다.
조종 자세: Leader 그리퍼 위쪽에 검지·중지, 아래쪽에 엄지를 두고 부드럽고 일정한 속도로 움직입니다. 급격한 동작은 Follower 안전과 이후 데이터 품질에 모두 불리합니다.
04

카메라 장치 확인

sudo apt update
sudo apt install v4l-utils
v4l2-ctl --list-devices

한 물리 카메라가 raw stream과 metadata 용도로 여러 /dev/video* 장치를 만들 수 있습니다. 장치명 아래에 나열된 경로 중 실제 영상 stream을 제공하는 번호를 사용합니다.

확인 항목설명
카메라 제품명내장·외장 카메라를 구분합니다.
/dev/videoX현재 부팅에서 할당된 영상 장치입니다.
해상도·FPS실습 명령의 640×480·30 FPS를 지원하는지 확인합니다.
05

카메라와 함께 원격 조종

lerobot-teleoperate \
  --robot.type=omx_follower \
  --robot.port=/dev/omx_follower \
  --robot.id=omx_follower_arm \
  --robot.cameras="{front: {type: opencv, index_or_path: '/dev/video0', width: 640, height: 480, fps: 30}}" \
  --teleop.type=omx_leader \
  --teleop.port=/dev/omx_leader \
  --teleop.id=omx_leader_arm \
  --display_data=true

/dev/video0은 예시이므로 앞 단계에서 확인한 카메라 경로로 바꿉니다. front는 이후 데이터셋에서 카메라를 구분하는 이름입니다.

Rerun Viewer 영역확인할 내용
카메라 영상프레임이 멈추거나 심하게 지연되지 않는가
관절 그래프Leader 입력과 Follower 상태가 부드럽게 변하는가
Observation·Action관측과 제어값이 같은 시간 흐름으로 갱신되는가
