01

LeRobot이란?

  • Hugging Face가 개발한 PyTorch 기반 오픈소스 로봇 학습 프레임워크입니다.
  • 데이터 수집 → 관리 → 정책 학습 → 평가 → 배포·공유를 하나의 생태계로 연결합니다.
  • 저가형 로봇 팔부터 모바일 로봇·휴머노이드까지 하드웨어 차이를 공통 인터페이스로 감쌉니다.
02

LeRobot이 해결하는 문제

기존 문제LeRobot의 접근효과
연구실마다 다른 데이터 형식LeRobotDataset데이터 공유·재사용
하드웨어에 묶인 제어 코드Robot 추상화동일한 제어 흐름 재사용
논문 재현 환경 부족SoTA 정책 구현과 평가 도구학습·평가 기준 통일
모델·데이터 배포 단절Hugging Face Hub 연동다운로드·스트리밍·공유
03

Robot 클래스와 Teleoperation

게임패드·키보드·Leader Robot
              ↓
         Teleoperation
              ↓
Camera + State + Action 동기화
              ↓
       LeRobotDataset 저장
  • Robot 클래스: 서로 다른 하드웨어의 연결·관측·명령을 공통 Python 인터페이스로 추상화합니다.
  • Teleoperation: 사람이 로봇을 조작하면서 성공 시연을 수집합니다.
  • 동기화: 한 프레임을 볼 때 로봇 상태와 실행한 행동이 정확히 대응해야 합니다.
04

LeRobotDataset v3 구조

폴더·형식저장 내용역할
meta/info·episode·task 메타데이터구조와 작업 정의
data/ · Parquetstate·action·timestamp빠른 수치 데이터 읽기와 압축
videos/ · MP4카메라별 영상비전 Observation
Frame index수치 행과 영상 프레임 연결시간 동기화
  • Episode: 한 작업을 시작부터 종료까지 수행한 기록입니다.
  • State: 현재 관절 각도와 그리퍼 상태입니다.
  • Action: 다음 관절·그리퍼 제어 명령입니다.
  • Observation: 카메라 영상과 State를 합친 Policy 입력입니다.
05

정책 모델의 범주

범주대표 모델특징
모방학습ACT·Diffusion Policy·VQ-BeT전문가 시연으로 행동 시퀀스 학습
강화학습HIL-SERL·TDMPC보상과 상호작용으로 정책 개선
VLAPi0Fast·Pi0.5·GR00T·SmolVLA·XVLA영상·언어·상태에서 행동 생성

ACT는 여러 미래 행동을 Chunk로 예측하고, Diffusion Policy는 노이즈에서 행동 시퀀스를 정제하며, VQ-BeT는 행동을 이산 토큰으로 표현합니다.

06

Vision-Language-Action 흐름

Camera + 자연어 지시 + Robot State
                  ↓
       Vision·Text·State Encoder
                  ↓
      VLM / Diffusion Transformer
                  ↓
            Action Decoder
                  ↓
        Robot-specific Motor Action
주의: Policy 출력은 명령 후보입니다. 관절 범위, 속도, 충돌, 센서 최신성, NaN/Inf 검사를 통과한 뒤 로봇에 전달합니다.
