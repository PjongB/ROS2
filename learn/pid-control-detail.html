03.12 SUPPLEMENT · CONTROL

PID 제어 상세 해설

목표와 현재 상태의 오차를 속도 명령으로 바꾸는 P·I·D 항의 역할과 Pinky Simple Navigator에서의 실제 적용 방법을 단계별로 살펴봅니다.

목차01 제어의 핵심02 P·I·D 항03 코드 읽기04 선속도 제어05 각속도 제어06 각도 정규화07 튜닝 방법08 코드의 한계
핵심PID 제어는 “목표에서 얼마나 벗어났는가”를 측정하고, 그 오차를 줄이는 방향으로 명령을 반복 계산하는 피드백 제어입니다.
01

오차를 줄이는 폐루프 제어

측정 → 비교 → 제어 → 재측정

목표값(goal) ─┐
              ├─ 오차(error) → PID → 속도 명령 → 로봇
현재값(TF) ───┘                              │
      ↑                                      │
      └──────────── 다시 측정 ────────────────┘

Simple Navigator는 0.1초마다 TF에서 현재 위치와 방향을 다시 읽습니다. 한 번 계산한 속도로 끝까지 움직이는 것이 아니라, 이동 결과를 다시 측정하고 다음 명령을 수정합니다.

02

P·I·D 세 항의 역할

u = Kp·e + Ki·Σe + Kd·Δe

  • P — 비례: 현재 오차가 클수록 강하게 움직입니다. 값이 너무 크면 목표 주변에서 빠르게 진동하고, 너무 작으면 반응이 느립니다.
  • I — 적분: 과거 오차를 누적해 작은 오차가 오래 남는 현상을 제거합니다. 너무 크면 누적값 때문에 목표를 지나쳐 계속 움직이는 wind-up이 발생할 수 있습니다.
  • D — 미분: 오차가 얼마나 빠르게 변하는지 보고 제동 역할을 합니다. overshoot와 진동을 줄이지만 센서 노이즈에 민감합니다.
P: 지금 얼마나 틀렸는가?
I: 지금까지 얼마나 오래 틀렸는가?
D: 오차가 얼마나 빠르게 변하는가?
03

예제 PID 클래스 읽기

simple_navigator.py

def update(self, error):
    self.integral += error
    derivative = error - self.previous_error
    self.previous_error = error
    return (self.P * error
            + self.I * self.integral
            + self.D * derivative)
  • integral은 지금까지의 오차를 더한 값입니다.
  • derivative는 이번 오차와 직전 오차의 차이입니다.
  • 새 목표를 받으면 reset()으로 이전 목표의 누적값을 지웁니다.
  • 현재 게인은 I=0이므로 실제 동작은 PID보다 PD 제어에 가깝습니다.
04

거리 오차를 선속도로 변환

move_to_goal 상태

dx = goal_x - current_x
dy = goal_y - current_y
distance_error = sqrt(dx² + dy²)
linear.x = linear_pid.update(distance_error)

목표가 멀면 거리 오차가 커져 빠르게 전진하고, 가까워지면 속도가 줄어듭니다. 예제의 선속도 게인은 P=0.5, I=0.0, D=0.1입니다.

05

방향 오차를 각속도로 변환

rotate_to_goal·move_to_goal·rotate_to_final

desired_heading = atan2(dy, dx)
error_angle = normalize_angle(
    desired_heading - current_yaw)
angular.z = angular_pid.update(error_angle)

양의 angular.z는 반시계 방향, 음의 값은 시계 방향 회전을 뜻합니다. 예제의 각속도 게인은 P=1.5, I=0.0, D=0.2이며, 직진 중에도 방향 오차를 계속 보정합니다.

06

각도 정규화가 필요한 이유

−π ≤ error ≤ π

def normalize_angle(angle):
    return atan2(sin(angle), cos(angle))

각도는 360°와 0°가 같은 순환 값입니다. 현재 방향이 179°이고 목표가 −179°일 때 단순 뺄셈은 −358°를 만들지만 실제 최단 회전은 2°입니다. 정규화는 항상 짧은 방향의 회전 오차를 선택합니다.

07

안전한 튜닝 순서

한 번에 하나의 값만 변경

  • 1단계: I와 D를 0으로 두고 P를 낮은 값부터 올려 반응 속도를 맞춥니다.
  • 2단계: 목표를 지나치거나 진동하면 D를 조금씩 올려 제동을 추가합니다.
  • 3단계: 마찰 때문에 작은 오차가 계속 남을 때만 I를 아주 작게 추가합니다.
  • 4단계: 각 변경 후 같은 시작 위치와 목표로 반복 시험합니다.
  • 느리게 접근: P가 너무 작을 가능성
  • 목표 주변 진동: P가 너무 크거나 D가 부족할 가능성
  • 반응이 거칠고 떨림: D가 너무 크거나 측정 노이즈가 큰 가능성
  • 한참 뒤 목표를 지나침: I가 과도하게 누적된 가능성
08

현재 예제 구현에서 주의할 점

교육용 단순 구현

  • 일반적인 PID는 적분과 미분에 제어 주기 dt를 반영하지만 예제는 단순히 오차를 더하고 뺍니다. 타이머 주기가 달라지면 같은 게인도 동작이 달라질 수 있습니다.
  • 선속도와 각속도에 상한이 없어 큰 오차에서 명령이 과도해질 수 있습니다. 실제 로봇에서는 최대 속도 제한이 필요합니다.
  • 적분 wind-up 방지, 미분 필터, 가속도 제한이 없습니다.
  • PID는 목표를 향하게 만들 뿐 장애물을 피할 경로는 생성하지 않습니다. 장애물 회피와 복구에는 Nav2의 planner·controller·costmap이 필요합니다.
