03.12 SUPPLEMENT · CONTROL

PID 제어 상세 해설

목표와 현재 상태의 오차를 속도 명령으로 바꾸는 P·I·D 항의 역할과 Pinky Simple Navigator에서의 실제 적용 방법을 단계별로 살펴봅니다.

핵심PID 제어는 “목표에서 얼마나 벗어났는가”를 측정하고, 그 오차를 줄이는 방향으로 명령을 반복 계산하는 피드백 제어입니다.
START

먼저 알아둘 네 가지 말

수식보다 개념부터

  • 목표값(Setpoint): 로봇이 도달해야 할 값입니다. 예: 목표 거리 0m, 목표 방향 0rad.
  • 현재값(Process value): 센서나 TF로 측정한 지금 상태입니다.
  • 오차(Error): 목표값 − 현재값입니다. PID가 입력으로 받는 핵심 값입니다.
  • 제어 입력(Control input): 오차를 줄이기 위해 로봇에 보내는 명령입니다. 이 예제에서는 linear.x와 angular.z입니다.
목표 방향 90° - 현재 방향 30° = 방향 오차 60°
목표 거리  0m  - 남은 거리  2m = 거리 오차 -2m

※ 코드에서는 거리의 크기를 양수로 계산해 전진 속도로 사용합니다.
01

오차를 줄이는 폐루프 제어

측정 → 비교 → 제어 → 재측정

목표값(goal) ─┐
              ├─ 오차(error) → PID → 속도 명령 → 로봇
현재값(TF) ───┘                              │
      ↑                                      │
      └──────────── 다시 측정 ────────────────┘

Simple Navigator는 0.1초마다 TF에서 현재 위치와 방향을 다시 읽습니다. 한 번 계산한 속도로 끝까지 움직이는 것을 개루프 제어라고 합니다. 반대로 이 예제처럼 결과를 계속 측정해 명령을 고치는 방식을 폐루프 또는 피드백 제어라고 합니다.

02

자동차 운전으로 이해하기

정지선에 부드럽게 멈추기

  • P는 가속 페달: 정지선이 멀면 세게 밟고 가까우면 약하게 밟습니다. 현재 거리만 보고 즉시 반응합니다.
  • I는 계속 남은 불만: 약한 오르막이나 마찰 때문에 조금 못 가고 있으면 남은 오차를 계속 모아 더 강한 힘을 냅니다.
  • D는 브레이크 감각: 정지선에 너무 빠르게 접근하고 있으면 미리 힘을 줄여 지나치는 것을 막습니다.

P만 있으면 간단하고 빠르지만 관성 때문에 목표를 지나칠 수 있습니다. D는 접근 속도를 보고 제동하며, I는 마찰처럼 지속적으로 남는 오차를 없애는 역할을 합니다.

03

P·I·D 세 항의 역할

u = Kp·e + Ki·Σe + Kd·Δe

  • P — 비례: 현재 오차가 클수록 강하게 움직입니다. 즉각적이고 이해하기 쉽지만 P만 너무 크면 목표를 계속 넘나들 수 있습니다.
  • I — 적분: 과거 오차를 누적해 작은 오차가 오래 남는 현상인 정상상태 오차를 제거합니다. 너무 크면 누적값 때문에 목표를 지나쳐 계속 움직이는 wind-up이 발생할 수 있습니다.
  • D — 미분: 오차가 얼마나 빠르게 변하는지 보고 미래의 움직임을 짐작하는 제동 역할을 합니다. overshoot와 진동을 줄이지만 센서 노이즈에 민감합니다.
P: 지금 얼마나 틀렸는가?
I: 지금까지 얼마나 오래 틀렸는가?
D: 오차가 얼마나 빠르게 변하는가?
04

P 제어 — 현재 오차에 즉시 반응

비례 제어 · uP = Kp × e

P 제어는 현재 오차에 비례하는 명령을 만듭니다. 목표가 멀면 큰 속도를 내고, 가까워질수록 속도를 줄입니다. 구조가 단순하고 반응이 빠르기 때문에 가장 먼저 맞추는 기본 제어입니다.

오차 2.0 × Kp 0.5 = 출력 1.0
오차 0.4 × Kp 0.5 = 출력 0.2
오차 0.1 × Kp 0.5 = 출력 0.05
  • Kp가 너무 작으면: 움직임이 느리고 마찰을 이기지 못해 목표 근처에서 멈출 수 있습니다.
  • Kp가 적당하면: 멀리서는 빠르고 가까이서는 부드럽게 감속합니다.
  • Kp가 너무 크면: 급격한 명령 때문에 목표를 지나치는 overshoot와 좌우 진동이 커집니다.

P 제어만으로도 오차가 작아지면 출력이 함께 작아집니다. 따라서 바닥 마찰이나 모터의 최소 구동력보다 출력이 작아지면 오차가 0이 아닌데도 움직이지 않는 정상상태 오차가 남을 수 있습니다.

05

I 제어 — 오래 남은 오차를 누적

적분 제어 · uI = Ki × ∫e(t)dt

I 제어는 오차의 크기뿐 아니라 오차가 얼마나 오래 지속되었는지를 봅니다. 작은 오차라도 계속 남아 있으면 누적값이 커져, 마찰·경사·모터 편차 때문에 P 제어가 끝내 없애지 못한 정상상태 오차를 밀어냅니다.

매 주기 오차가 0.1이라면
누적 오차: 0.1 → 0.2 → 0.3 → 0.4 → ...
I 출력:    Ki × 누적 오차
  • 장점: 계속 남는 거리 오차나 방향 치우침을 0에 가깝게 만듭니다.
  • Ki가 너무 작으면: 정상상태 오차를 없애는 데 오래 걸립니다.
  • Ki가 너무 크면: 누적된 힘이 목표 도달 후에도 남아 overshoot와 느린 진동을 만듭니다.
  • Wind-up: 속도 제한이나 장애물 때문에 로봇이 움직이지 못하는 동안 적분값만 계속 쌓이는 현상입니다. 제한이 풀리면 과도한 출력이 한꺼번에 나옵니다.

실제 제어기에서는 적분값의 상한을 정하거나, 출력이 포화된 동안 적분을 멈추는 anti-windup을 사용합니다. 이 강의 코드의 I=0.0은 적분을 사용하지 않는다는 뜻입니다.

06

D 제어 — 변화 속도를 보고 미리 제동

미분 제어 · uD = Kd × de(t)/dt

D 제어는 오차 자체보다 오차가 변하는 속도를 봅니다. 목표에 빠르게 접근해 오차가 급격히 줄고 있다면 제동을 걸어, 관성으로 목표를 지나치는 것을 억제합니다. 그래서 흔히 예측 브레이크 또는 감쇠 역할이라고 설명합니다.

직전 오차 1.0 → 현재 오차 0.4
오차 변화량 = 0.4 - 1.0 = -0.6
접근 속도가 빠르므로 D 항이 P 출력을 줄이는 방향으로 작용
  • 장점: overshoot와 진동을 줄이고 목표 근처에서 안정적으로 멈추게 합니다.
  • Kd가 너무 작으면: 제동이 부족해 목표를 반복해서 지나칠 수 있습니다.
  • Kd가 너무 크면: 움직임이 둔해지고 센서값의 작은 떨림에도 명령이 크게 출렁일 수 있습니다.
  • 노이즈 민감성: 측정값이 조금만 튀어도 순간 변화량은 크게 계산되므로 보통 저역 통과 필터를 함께 사용합니다.

D 제어는 단독으로 목표까지 움직이게 하기보다 P 제어가 만든 움직임을 안정시키는 용도로 주로 사용합니다.

07

제어 결과를 읽는 핵심 용어

목표에 도달하는 응답 곡선을 관찰

  • 상승 시간(Rise time): 출발 후 목표값 근처까지 처음 도달하는 시간입니다. 짧을수록 반응은 빠르지만 overshoot가 커질 수 있습니다.
  • Overshoot(오버슈트): 목표를 처음 지나쳐 반대편까지 간 양입니다. 1m 목표에서 1.1m까지 갔다면 최대 overshoot는 0.1m입니다.
  • Undershoot(언더슈트): 목표를 지난 뒤 되돌아오면서 목표 반대편으로 다시 벗어난 양입니다. 큰 undershoot는 진동이 강하다는 신호입니다.
  • 진동(Oscillation): 오차의 부호가 반복해서 바뀌며 목표 양쪽을 오가는 현상입니다.
  • 정착 시간(Settling time): 출력이 허용 오차 범위에 들어온 뒤 다시 벗어나지 않을 때까지 걸린 시간입니다.
  • 정상상태 오차(Steady-state error): 충분한 시간이 지난 뒤에도 목표와 현재값 사이에 남는 오차입니다.
목표 ─────────────────────────
응답 ─────╱╲___╱‾╲__────────
            ↑       ↑
       overshoot  작은 진동 후 정착

좋은 제어는 무조건 빠른 제어가 아닙니다. 상승 시간, overshoot, 정착 시간, 정상상태 오차 사이에서 로봇과 환경에 맞는 균형을 찾는 것이 중요합니다.

08

실제 로봇에서 함께 알아야 할 현상

수식 밖의 모터·센서·출력 제한

  • Deadband(불감대): 명령이 너무 작아서 모터가 움직이지 않는 구간입니다. 작은 P 출력이 불감대에 걸리면 정상상태 오차가 남습니다.
  • Tolerance(허용 오차): 완벽한 0 대신 “이 범위 안이면 도착”으로 판단하는 값입니다. 센서 노이즈 속에서 로봇이 끝없이 미세 조정하는 것을 막습니다.
  • Saturation(출력 포화): 계산 결과가 모터의 최대 속도를 넘어도 실제 출력은 더 커질 수 없는 상태입니다.
  • Integral wind-up: 출력이 포화되었는데도 I 항이 계속 누적돼 나중에 큰 overshoot를 만드는 현상입니다.
  • 센서 노이즈: 위치나 각도 측정의 작은 흔들림입니다. 특히 변화량을 사용하는 D 항을 불안정하게 만들 수 있습니다.

따라서 실전 PID에는 최대 속도 제한, 허용 오차, 적분 제한, 미분 필터, 가속도 제한이 함께 들어가는 경우가 많습니다.

09

예제 PID 클래스 읽기

simple_navigator.py

def update(self, error):
    self.integral += error
    derivative = error - self.previous_error
    self.previous_error = error
    return (self.P * error
            + self.I * self.integral
            + self.D * derivative)
  • integral은 지금까지의 오차를 더한 값입니다.
  • derivative는 이번 오차와 직전 오차의 차이입니다.
  • 새 목표를 받으면 reset()으로 이전 목표의 누적값을 지웁니다.
  • 현재 게인은 I=0이므로 실제 동작은 PID보다 PD 제어에 가깝습니다.
10

거리 오차를 선속도로 변환

move_to_goal 상태

dx = goal_x - current_x
dy = goal_y - current_y
distance_error = sqrt(dx² + dy²)
linear.x = linear_pid.update(distance_error)

목표가 멀면 거리 오차가 커져 빠르게 전진하고, 가까워지면 속도가 줄어듭니다. 예제의 선속도 게인은 P=0.5, I=0.0, D=0.1입니다.

11

방향 오차를 각속도로 변환

rotate_to_goal·move_to_goal·rotate_to_final

desired_heading = atan2(dy, dx)
error_angle = normalize_angle(
    desired_heading - current_yaw)
angular.z = angular_pid.update(error_angle)

양의 angular.z는 반시계 방향, 음의 값은 시계 방향 회전을 뜻합니다. 예제의 각속도 게인은 P=1.5, I=0.0, D=0.2이며, 직진 중에도 방향 오차를 계속 보정합니다.

12

각도 정규화가 필요한 이유

−π ≤ error ≤ π

def normalize_angle(angle):
    return atan2(sin(angle), cos(angle))

각도는 360°와 0°가 같은 순환 값입니다. 현재 방향이 179°이고 목표가 −179°일 때 단순 뺄셈은 −358°를 만들지만 실제 최단 회전은 2°입니다. 정규화는 항상 짧은 방향의 회전 오차를 선택합니다.

13

안전한 튜닝 순서

한 번에 하나의 값만 변경

  • 1단계: I와 D를 0으로 두고 P를 낮은 값부터 올려 반응 속도를 맞춥니다.
  • 2단계: 목표를 지나치거나 진동하면 D를 조금씩 올려 제동을 추가합니다.
  • 3단계: 마찰 때문에 작은 오차가 계속 남을 때만 I를 아주 작게 추가합니다.
  • 4단계: 각 변경 후 같은 시작 위치와 목표로 반복 시험합니다.
  • 느리게 접근: P가 너무 작을 가능성
  • 목표 주변 진동: P가 너무 크거나 D가 부족할 가능성
  • 반응이 거칠고 떨림: D가 너무 크거나 측정 노이즈가 큰 가능성
  • 한참 뒤 목표를 지나침: I가 과도하게 누적된 가능성
14

Pinky의 현재 설정 해석

I가 0이므로 실제로는 PD 제어

  • 선속도: P=0.5, I=0.0, D=0.1 — 거리 오차로 전진 속도를 만들고 D 항으로 목표 근처의 급격한 접근을 완화합니다.
  • 각속도: P=1.5, I=0.0, D=0.2 — 방향 오차에 더 강하게 반응하며 회전 overshoot를 D 항으로 억제합니다.
  • 거리 허용 오차: 약 0.15m 안에 들어오면 위치 도달로 판단합니다.
  • 각도 허용 오차: 약 0.05rad, 즉 약 2.9° 안에 들어오면 회전을 마칩니다.

테스트할 때는 먼저 목표 주변에서 좌우로 흔들리는지, 목표를 지나쳤다가 돌아오는지, 조금 남겨 두고 멈추는지를 관찰합니다. 흔들림이 크면 P를 낮추거나 D를 조금 높이고, 지나치게 느리면 P를 조금 높입니다. I는 지속적인 오차가 실제로 확인될 때만 작게 추가하는 편이 안전합니다.

15

현재 예제 구현에서 주의할 점

교육용 단순 구현

  • 일반적인 PID는 적분과 미분에 제어 주기 dt를 반영하지만 예제는 단순히 오차를 더하고 뺍니다. 타이머 주기가 달라지면 같은 게인도 동작이 달라질 수 있습니다.
  • 선속도와 각속도에 상한이 없어 큰 오차에서 명령이 과도해질 수 있습니다. 실제 로봇에서는 최대 속도 제한이 필요합니다.
  • 적분 wind-up 방지, 미분 필터, 가속도 제한이 없습니다.
  • PID는 목표를 향하게 만들 뿐 장애물을 피할 경로는 생성하지 않습니다. 장애물 회피와 복구에는 Nav2의 planner·controller·costmap이 필요합니다.
