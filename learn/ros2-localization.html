Localization

저장한 지도 위에서 AMCL 파티클 필터로 Pinky Pro의 위치와 방향을 추정하고 RViz2에서 검증하는 실습입니다.

한 줄 정리SLAM은 지도를 만들며 위치를 추정하고, Localization은 이미 만든 지도에서 현재 위치를 찾습니다.
실습 전 필수제공된 localization_only_launch.xml을 pinky_navigation/launch에, amcl_params.yaml을 pinky_navigation/params에 복사한 뒤 colcon build하고 새 install/setup.bash를 source해야 합니다.
KEY

반드시 기억할 핵심 포인트

Localization 실습 체크리스트

  • 필수 입력: 저장된 my_map.yaml, LiDAR /scan, odometry와 TF가 필요합니다.
  • 핵심 노드: map_server가 /map을 발행하고 amcl이 센서 결과와 지도를 비교합니다.
  • 초기화: RViz2의 2D Pose Estimate로 로봇의 대략적인 위치와 방향을 지정해야 합니다.
  • 출력: 추정 위치는 /amcl_pose, 전체 TF는 map → odom → base_footprint로 확인합니다.
  • 수렴 판단: 로봇을 주행시켰을 때 RViz의 녹색 파티클 화살표가 한 지점으로 모이면 위치 추정이 수렴한 것입니다.
  • Pinky 프레임: 제공된 예제는 base_link를 쓰지만 현재 Pinky 네비게이션 설정은 base_footprint입니다. 실제 TF 트리와 일치시키세요.
01

Localization의 의미

원본 1.1

  • 지도 기준 좌표에서 로봇이 어디에 있고 어느 방향을 보는지 계속 추정합니다.
  • AMCL은 여러 가설 위치를 파티클로 표현하고 LiDAR 관측에 맞는 가설의 가중치를 높입니다.
  • 로봇이 움직이면 odometry 예측과 LaserScan 관측이 누적되어 분포가 줄어듭니다.
02

실행 순서

원본 1.3

  • Gazebo를 실행하고 저장한 맵 YAML이 있는 위치에서 localization launch를 시작합니다.
  • Lifecycle Manager의 Creating bond timer 로그가 나오면 map server와 AMCL의 활성화 연결이 진행된 것입니다.
  • nav2_view.launch.xml로 RViz2를 열고 초기 위치를 지정한 뒤 주행합니다.
03

2D Pose Estimate로 초기 위치 지정

원본 1.3.6–1.3.12

  • RViz의 Fixed Frame은 map으로 설정합니다.
  • 지도에서 로봇의 실제 위치를 누르고 드래그해 보는 방향을 지정합니다.
  • 잘못된 초기 자세를 주면 LaserScan과 벽이 맞지 않고 파티클이 수렴하지 않습니다.
04

amcl_params.yaml

원본 2.4

  • use_map_topic: true로 map server의 /map을 사용합니다.
  • min_particles: 500, max_particles: 3000으로 파티클 범위를 설정합니다.
  • update_min_d: 0.1은 0.1m 이동, update_min_a: 0.2는 약 11.5° 회전 후 추정을 갱신한다는 뜻입니다.
  • tf_broadcast: true면 AMCL이 map → odom TF를 발행합니다.
05

Lifecycle Manager

원본 2.2–2.3

  • Nav2 노드는 unconfigured → inactive → active → finalized 상태를 가집니다.
  • Lifecycle Manager가 map_server와 amcl을 순서대로 configure·activate합니다.
  • autostart: true와 node_names: ['map_server', 'amcl']이 자동 활성화의 핵심입니다.
06

위치 추정 검증

원본 1.3.10–1.3.17

  • 키보드로 로봇을 천천히 이동시키며 파티클 분포와 LaserScan 정렬을 관찰합니다.
  • ros2 topic echo /amcl_pose로 위치·자세와 공분산을 확인합니다.
  • RViz Publish Point를 사용하면 /clicked_point 토픽으로 지도 좌표를 확인할 수 있습니다.

핵심 실행 명령

source /opt/ros/jazzy/setup.bash
source ~/pinky/install/setup.bash

# 1. Gazebo
ros2 launch pinky_gz_sim launch_sim.launch.xml

# 2. my_map.yaml이 있는 폴더에서 Localization
cd ~/pinky
ros2 launch pinky_navigation localization_only_launch.xml map:=my_map.yaml

# 3. RViz2
ros2 launch pinky_navigation nav2_view.launch.xml

# 4. 초기 위치 지정 후 주행
ros2 run teleop_twist_keyboard teleop_twist_keyboard

# 5. 위치 추정 결과
ros2 topic echo /amcl_pose
ros2 topic echo /clicked_point
