03

목표 Pose 구성

PoseStamped의 frame은 map, timestamp는 navigator clock을 사용합니다. 위치 x/y와 방향 quaternion을 모두 지정합니다.

from geometry_msgs.msg import PoseStamped

goal_pose = PoseStamped()
goal_pose.header.frame_id = 'map'
goal_pose.header.stamp = navigator.get_clock().now().to_msg()
goal_pose.pose.position.x = 1.5
goal_pose.pose.position.y = 0.55

# 약 90도 회전: z=sin(45°), w=cos(45°)
goal_pose.pose.orientation.z = 0.707
goal_pose.pose.orientation.w = 0.707

w=1.0, z=0.0은 회전 없는 방향이고, PDF 예제의 z=w=0.707은 약 90도 방향입니다. 목표 위치는 RViz Publish Point로 확인합니다.

05

여러 좌표 주행

여러 PoseStamped를 리스트에 담아 followWaypoints()로 전달합니다. 각 점의 frame, timestamp, 위치와 orientation을 모두 지정합니다.

1 · 단일 목표 전송과 피드백

from rclpy.duration import Duration
from nav2_simple_commander.robot_navigator import TaskResult

navigator.goToPose(goal_pose)
i = 0
while not navigator.isTaskComplete():
    i += 1
    feedback = navigator.getFeedback()
    if feedback and i % 5 == 0:
        print(f'Distance remaining: {feedback.distance_remaining:.2f} meters')

        # 10분을 넘으면 안전하게 취소
        if Duration.from_msg(feedback.navigation_time) > Duration(seconds=600.0):
            navigator.cancelTask()

result = navigator.getResult()
if result == TaskResult.SUCCEEDED:
    print('Goal succeeded!')
elif result == TaskResult.CANCELED:
    print('Goal was canceled!')
elif result == TaskResult.FAILED:
    print('Goal failed!')
else:
    print('Goal has an invalid return status!')

2 · 다중 Waypoint 만들기

def make_pose(x, y, z=0.0, w=1.0):
    pose = PoseStamped()
    pose.header.frame_id = 'map'
    pose.header.stamp = navigator.get_clock().now().to_msg()
    pose.pose.position.x = x
    pose.pose.position.y = y
    pose.pose.orientation.z = z
    pose.pose.orientation.w = w
    return pose

goal_pose_list = [
    make_pose(1.5, 0.55, 0.707, 0.707),
    make_pose(1.5, -3.75, 0.707, 0.707),
    make_pose(-3.6, -4.75, 0.707, 0.707),
]

3 · Waypoint 실행과 진행 상황

navigator.followWaypoints(goal_pose_list)
start_time = navigator.get_clock().now()
i = 0

while not navigator.isTaskComplete():
    i += 1
    feedback = navigator.getFeedback()
    if feedback and i % 5 == 0:
        print(
            f'Executing waypoint: {feedback.current_waypoint + 1}/'
            f'{len(goal_pose_list)}'
        )

    if navigator.get_clock().now() - start_time > Duration(seconds=600.0):
        navigator.cancelTask()  # PDF의 navigator/nav 변수 혼용 오타를 수정

print(navigator.getResult())
