01

실행 준비

  • SBC bringup과 PC Navigation을 먼저 실행합니다.
  • RViz에서 2D Pose Estimate로 초기 위치를 맞춥니다.
  • Nav2 환경이 source된 터미널에서 Jupyter Notebook을 실행합니다.
02

BasicNavigator 초기화

import rclpy
from nav2_simple_commander.robot_navigator import BasicNavigator

rclpy.init()
navigator = BasicNavigator()
navigator.waitUntilNav2Active()
03

목표 Pose 구성

PoseStamped의 frame은 map, timestamp는 navigator clock을 사용합니다. 위치 x/y와 방향 quaternion을 모두 지정합니다.

04

피드백과 결과

isTaskComplete()가 거짓인 동안 getFeedback()으로 남은 거리·경과 시간을 확인합니다. 완료되면 getResult()로 성공·취소·실패를 구분합니다.

05

여러 좌표 주행

여러 PoseStamped를 리스트에 담아 followWaypoints()로 전달합니다. 각 점의 좌표계와 orientation을 빠뜨리지 않습니다.

단일 목표 코드 흐름

from geometry_msgs.msg import PoseStamped

goal = PoseStamped()
goal.header.frame_id = 'map'
goal.header.stamp = navigator.get_clock().now().to_msg()
goal.pose.position.x = 1.0
goal.pose.position.y = 0.5
goal.pose.orientation.w = 1.0

navigator.goToPose(goal)
while not navigator.isTaskComplete():
    feedback = navigator.getFeedback()
    if feedback:
        print(feedback.distance_remaining)

print(navigator.getResult())
navigator.lifecycleShutdown()
rclpy.shutdown()

완료 체크

  1. Nav2가 Active가 된 뒤 목표를 보냅니다.
  2. 목표 frame과 timestamp가 유효합니다.
  3. 주행 중 피드백이 갱신됩니다.
  4. 결과를 확인하고 navigator와 rclpy를 종료합니다.

FIX

문제 해결

  • Navigator가 Active에서 대기: Nav2 lifecycle 노드와 map·AMCL 초기화를 확인합니다.
  • 목표가 거부됨: frame_id='map', timestamp와 목표가 자유 공간인지 확인합니다.
  • Notebook 재실행 오류: 기존 rclpy context를 shutdown한 뒤 kernel을 재시작합니다.
  • Waypoint 일부 실패: getResult()와 missed waypoint 정보를 기록합니다.
  • 중간 취소: 필요할 때 navigator.cancelTask()를 호출하고 결과를 확인합니다.
