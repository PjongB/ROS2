PinkyPro를 소개합니다

ROS 2 자율주행 수업을 위해 만들어진 작은 모바일 로봇 PinkyPro의 탄생 배경, 구성, 활용 미션과 학습 흐름을 연결해서 이해합니다.

한 줄 정리PinkyPro는 ROS 2의 통신·TF·센서·SLAM·Nav2를 실제 모바일 로봇 한 대에서 단계적으로 연결하는 교육용 플랫폼입니다.
MAP

PinkyPro 학습 전체 구조

환경 준비 → 구동 → 인식 → 자율주행 → 응용

환경 설정OS·워크스페이스·SSH
로봇 구동bringup·teleop·topic
지도·위치SLAM·Map·AMCL
자율주행Nav2·AI·협동
  • PC: 개발, RViz 시각화, 명령과 상위 애플리케이션을 담당합니다.
  • 로봇: 모터·센서를 구동하고 ROS 2 토픽과 TF를 제공합니다.
  • 네트워크: 같은 DDS 도메인에서 PC와 로봇의 노드가 서로 발견됩니다.
01

왜 PinkyPro인가

원본: Pinky 등장!

  • 자율주행 로봇 수업에서 필요한 기능을 한 플랫폼에 담기 위해 만들어졌습니다.
  • ROS 2의 노드·토픽·TF·센서·SLAM·Nav2를 실제 하드웨어에서 연결해 볼 수 있습니다.
  • 작은 크기로 교실과 실험실에서 반복 실습하기 좋습니다.
02

우리가 사용할 모바일 로봇

원본: PinkyPro 소개

  • 차동 구동 모바일 베이스와 센서를 이용해 주변 환경을 인식하고 이동합니다.
  • 최대 약 50g까지 상차할 수 있어 간단한 운반 미션을 구성할 수 있습니다.
  • 실제 로봇과 PC를 같은 ROS 도메인으로 연결해 분산 실행합니다.
03

Pinky가 할 수 있는 일

원본: 활용 예시

  • 자율주행과 물체 운반, 다양한 딥러닝 기반 미션을 수행할 수 있습니다.
  • 로봇팔과 협동하거나 여러 대의 로봇을 동시에 관제하는 서비스로 확장할 수 있습니다.
  • LLM과 비전·행동을 연결한 VLA 응용도 실험할 수 있습니다.
04

한 대의 로봇에서 시스템 프로젝트로

AI·로봇팔·다중 로봇·VLA

  • 카메라 인식 결과를 ROS 2 토픽으로 발행해 주행 조건과 연결합니다.
  • 로봇팔과 위치·작업 완료 신호를 교환해 운반과 조작을 연계합니다.
  • namespace와 도메인을 설계해 여러 로봇의 토픽 충돌을 피합니다.
  • 자연어 요청은 실행 가능한 목표와 행동으로 변환한 뒤 안전 규칙으로 검증합니다.
05

추천 학습 경로

소개 → 환경 설정 → 지도 작성 → Localization → Nav2

  1. 로봇과 PC의 네트워크·ROS 2 환경을 준비합니다.
  2. bringup과 teleop으로 센서와 구동부를 검증합니다.
  3. SLAM으로 지도를 만들고 파일을 저장합니다.
  4. AMCL로 저장 지도 위 위치를 추정합니다.
  5. Nav2로 목표 설정, 경로 계획과 추종을 실습합니다.

학습 전 체크리스트

  1. PinkyPro와 PC의 역할을 설명할 수 있습니다.
  2. 토픽과 TF가 센서·구동·자율주행을 연결하는 흐름을 이해했습니다.
  3. 환경 설정부터 Nav2까지의 실습 순서를 파악했습니다.
  4. 저속 주행과 비상 정지 방법을 먼저 확인합니다.
