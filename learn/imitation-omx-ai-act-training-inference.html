01

ACT: Action Chunking with Transformers

ACT는 한 observation에서 다음 한 동작이 아니라 짧은 미래 action sequence를 한 번에 예측합니다. Transformer 기반 encoder-decoder로 시연의 시간 구조를 학습해 step별 오차 누적을 줄이고 부드러운 조작을 만듭니다.

  • 입력: 카메라 이미지와 현재 로봇 state
  • 출력: 여러 step의 목표 관절값 action chunk
  • 학습 자료: Teleoperation으로 모은 성공 demonstration
02

ACT 모델 학습

source ~/venv/il/bin/activate
HF_USER=$(hf auth whoami | head -n 1 | sed 's/\x1b\[[0-9;]*m//g' | awk -F': ' '{print $2}' | xargs)

cd ~/il_ws/src/lerobot
lerobot-train \
  --dataset.repo_id=${HF_USER}/record-test-clean \
  --policy.type=act \
  --output_dir=outputs/train/omx_act_policy \
  --job_name=act_record-test \
  --policy.device=cuda \
  --wandb.enable=false \
  --policy.repo_id=${HF_USER}/omx_act_policy \
  --batch_size=16 \
  --save_checkpoint=true \
  --save_freq=10000 \
  --steps=100000
인자운영 기준
batch_sizeVRAM 부족/OOM이면 먼저 줄입니다.
steps너무 작으면 underfit, 너무 크면 overfit을 검증 loss·평가로 판단합니다.
save_freq복구 손실과 disk 사용량 사이에서 정합니다.
wandb.enable사용할 때만 로그인하고 loss·learning rate를 추적합니다.

04

동기 추론과 평가 기록

실물 실행: 학습된 action은 안전이 보장된 명령이 아닙니다. 로봇을 고정하고 관절 범위·속도·비상 정지·작업 공간을 먼저 확인합니다.
lerobot-record \
  --robot.type=omx_follower \
  --robot.port=/dev/omx_follower \
  --robot.id=omx_follower_arm \
  --robot.cameras="{front: {type: opencv, index_or_path: 0, width: 640, height: 480, fps: 30}}" \
  --display_data=true \
  --dataset.repo_id=${HF_USER}/eval_act_omx \
  --dataset.single_task="Pick up Doll and put in cup" \
  --dataset.num_episodes=10 \
  --dataset.push_to_hub=false \
  --policy.path=${HF_USER}/omx_act_policy

eval_* 이름으로 학습 자료와 평가 결과를 구분합니다. 평가 dataset의 자동 업로드는 필요할 때만 켭니다.

06

비동기 추론

동기 방식은 action queue가 비면 다음 추론을 기다리며 멈춥니다. 비동기 방식은 현재 chunk를 실행하는 동안 다음 observation을 보내 새 chunk를 미리 계산하고, 겹친 구간을 집계해 끊김을 줄입니다.

TERMINAL 1 · POLICY SERVER
python -m lerobot.async_inference.policy_server \
  --host=127.0.0.1 \
  --port=8080 \
  --fps=30 \
  --inference_latency=0.033 \
  --obs_queue_timeout=1
TERMINAL 2 · ROBOT CLIENT
python -m lerobot.async_inference.robot_client \
  --robot.type=omx_follower \
  --robot.port=/dev/omx_follower \
  --robot.id=omx_follower_arm \
  --robot.cameras="{front: {type: opencv, index_or_path: 0, width: 640, height: 480, fps: 30}}" \
  --task="Pick up Doll and put in cup" \
  --server_address=127.0.0.1:8080 \
  --policy_type=act \
  --pretrained_name_or_path=${HF_USER}/omx_act_policy \
  --policy_device=cuda \
  --actions_per_chunk=100 \
  --chunk_size_threshold=0.5 \
  --aggregate_fn_name=weighted_average
버전 고정: 비동기 module과 CLI 인자는 LeRobot version에 따라 달라질 수 있습니다. 이 강의의 v0.4.4 환경과 PDF 명령을 기준으로 실행하고, 실제 설치본의 --help를 함께 확인합니다.
07

평가 지표와 안전 게이트

  • Task 성공률, 완료 시간, 재시도 횟수와 실패 유형을 episode별로 기록합니다.
  • NaN/Inf, 관절 범위, 한 step 변화량, camera timestamp를 실행 전에 검사합니다.
  • 추종 오차·전류 급증·frame drop을 감시하고 이상 시 hold 또는 safe stop으로 전환합니다.
  • 같은 평가 조건에서 checkpoint별 결과를 비교해 최고 모델을 선택합니다.
