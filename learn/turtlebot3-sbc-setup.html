01

Ubuntu Server microSD 만들기

  1. sudo apt install rpi-imager 후 Imager를 실행합니다.
  2. Raspberry Pi 4와 Ubuntu Server 24.04 64-bit를 선택합니다.
  3. Username·Password·Wi-Fi·시간대와 SSH를 설정합니다.
  4. 대상 microSD의 장치명과 용량을 다시 확인하고 기록합니다.
  5. Pi에 삽입하고 HDMI·키보드를 연결해 첫 부팅을 확인합니다.
주의: Storage 선택을 틀리면 다른 디스크의 데이터가 지워질 수 있습니다.
02

IP 확인과 PC SSH 접속

# SBC
ip a

# Wi-Fi IP가 없을 때
sudo nano /etc/netplan/50-cloud-init.yaml
sudo netplan apply

# PC
ssh <username>@<robot-ip>

wlan0의 inet 주소를 사용하고 PC와 로봇을 같은 공유기에 연결합니다.

03

ROS 2 Jazzy 설치 - 터미널에서 그대로 입력

# 1. UTF-8 locale
sudo apt update
sudo apt install locales -y
sudo locale-gen en_US en_US.UTF-8
sudo update-locale LC_ALL=en_US.UTF-8 LANG=en_US.UTF-8
export LANG=en_US.UTF-8
locale

# 2. Universe와 ROS 2 APT source
sudo apt install software-properties-common -y
sudo add-apt-repository universe
sudo apt update
sudo apt install curl -y
export ROS_APT_SOURCE_VERSION=$(curl -s https://api.github.com/repos/ros-infrastructure/ros-apt-source/releases/latest | grep -F "tag_name" | awk -F'"' '{print $4}')
curl -L -o /tmp/ros2-apt-source.deb "https://github.com/ros-infrastructure/ros-apt-source/releases/download/${ROS_APT_SOURCE_VERSION}/ros2-apt-source_${ROS_APT_SOURCE_VERSION}.$(. /etc/os-release && echo ${UBUNTU_CODENAME:-${VERSION_CODENAME}})_all.deb"
sudo dpkg -i /tmp/ros2-apt-source.deb

# 3. ROS Base와 개발 도구
sudo apt update
sudo apt upgrade -y
sudo apt install ros-dev-tools ros-jazzy-ros-base -y

# 4. 현재 터미널 적용·확인
source /opt/ros/jazzy/setup.bash
ros2 --help
공식 Jazzy 설치 절차 기준: Ubuntu 24.04 ARM64에서 APT source package를 등록하는 현재 방식입니다. 명령 전체를 한 번에 붙이지 말고 번호별로 성공 여부를 확인합니다. ROS 2 Jazzy Ubuntu 설치 문서 열기
04

TurtleBot3 패키지와 빌드

sudo apt install python3-argcomplete python3-colcon-common-extensions \
  libboost-system-dev build-essential libudev-dev
sudo apt install ros-jazzy-hls-lfcd-lds-driver ros-jazzy-turtlebot3-msgs \
  ros-jazzy-dynamixel-sdk ros-jazzy-xacro

mkdir -p ~/turtlebot3_ws/src
cd ~/turtlebot3_ws/src
git clone -b jazzy https://github.com/ROBOTIS-GIT/turtlebot3.git
git clone -b jazzy https://github.com/ROBOTIS-GIT/ld08_driver.git
git clone -b jazzy https://github.com/ROBOTIS-GIT/coin_d4_driver

# SBC에는 SLAM·Navigation GUI 패키지가 필요 없음
cd ~/turtlebot3_ws/src/turtlebot3
rm -r turtlebot3_cartographer turtlebot3_navigation2

cd ~/turtlebot3_ws
colcon build --symlink-install --parallel-workers 1

삭제 명령은 정확히 위 두 패키지 폴더에서만 실행합니다. 단일 worker는 Pi의 메모리 부담을 줄입니다.

05

OpenCR udev·Domain·모델 설정

sudo cp `ros2 pkg prefix turtlebot3_bringup`/share/turtlebot3_bringup/script/99-turtlebot3-cdc.rules /etc/udev/rules.d/
sudo udevadm control --reload-rules
sudo udevadm trigger

# PC와 같은 값
export ROS_DOMAIN_ID=30
export TURTLEBOT3_MODEL=burger

# 실제 센서에 맞춰 하나만 선택
export LDS_MODEL=LDS-01   # 또는 LDS-02 / LDS-03

검증 후 필요한 값만 ~/.bashrc에 한 번 추가합니다. grep -n 'ROS_DOMAIN_ID\|TURTLEBOT3_MODEL\|LDS_MODEL' ~/.bashrc로 중복을 확인합니다.

06

OpenCR 펌웨어

sudo dpkg --add-architecture armhf
sudo apt-get update
sudo apt-get install libc6:armhf

export OPENCR_MODEL=burger
export OPENCR_PORT=/dev/ttyACM0
wget https://github.com/ROBOTIS-GIT/OpenCR-Binaries/raw/master/turtlebot3/ROS2/latest/opencr_update.tar.bz2
tar -xvf opencr_update.tar.bz2
cd opencr_update
./update.sh $OPENCR_PORT $OPENCR_MODEL.opencr
  • Waffle은 모델 값을 알맞게 변경합니다.
  • ls -l /dev/ttyACM*로 포트를 먼저 확인합니다.
  • 업로드 중 전원이나 USB를 분리하지 않습니다.

터미널에 입력하는 전체 실행 순서

FIX

문제 해결과 안전

  • SSH 실패: 전원 → IP → 같은 서브넷 → ping → SSH 순서로 확인합니다.
  • 토픽이 안 보임: 양쪽 setup, Domain ID, 네트워크와 방화벽을 확인합니다.
  • /dev/ttyACM0 없음: OpenCR 전원·USB·udev 규칙을 확인합니다.
  • LiDAR가 안 돎: LDS 모델, 드라이버와 센서 전원을 확인합니다.
  • 빌드 중 멈춤: 단일 worker, swap·저장공간·온도를 확인합니다.
  • 모터가 반응하지 않음: firmware 모델, 배터리와 /cmd_vel을 확인합니다.
첫 구동: 바퀴를 들어 올리고 저속 명령과 정지 키부터 검증합니다.
