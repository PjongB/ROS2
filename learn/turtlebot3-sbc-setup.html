06.03 · TURTLEBOT3 · RASPBERRY PI

TurtleBot3 SBC Setup

Raspberry Pi 4에 Ubuntu Server 24.04와 ROS 2 Jazzy를 설치하고 OpenCR·LiDAR·PC 통신을 준비합니다.

원본 HTML체크리스트 ↓
목차SD 이미지네트워크ROS 2로봇 패키지OpenCR검증
역할 구분SBC는 센서·모터와 bringup을 담당하고, PC는 RViz·SLAM·Nav2·teleop을 담당합니다. 둘은 같은 네트워크와 ROS Domain을 사용합니다.
01

Ubuntu Server SD 카드

  • Raspberry Pi Imager에서 Raspberry Pi 4와 Ubuntu Server 24.04 64-bit를 선택합니다.
  • 사용자 이름·비밀번호·Wi-Fi·시간대·SSH를 미리 설정합니다.
  • 저장장치가 올바른 microSD인지 재확인한 뒤 기록합니다.
02

부팅·IP·SSH

hostname -I
ssh <사용자명>@<로봇_IP>
ping -c 3 google.com

IP가 없다면 Wi-Fi 설정과 공유기 연결부터 해결합니다. 인터넷, SSH, 시간 동기화가 된 뒤 패키지 설치로 넘어갑니다.

03

ROS 2 Jazzy

공식 Ubuntu 설치 절차로 locale·Universe·ROS APT 저장소를 설정하고 ros-jazzy-ros-base와 개발 도구를 설치합니다. 설치 뒤 /opt/ros/jazzy/setup.bash를 source합니다.

04

TurtleBot3 패키지와 환경변수

export ROS_DOMAIN_ID=<수업 도메인>
export TURTLEBOT3_MODEL=burger
export LDS_MODEL=LDS-02

실제 장착 모델에 따라 LDS-01 또는 LDS-02를 선택하며 PC의 Domain ID도 같아야 합니다.

05

OpenCR 연결

  • OpenCR용 udev 규칙을 적용하고 USB 연결을 확인합니다.
  • Burger에 맞는 OpenCR 펌웨어를 내려받아 업로드합니다.
  • 배터리를 연결하고 bringup 로그에서 모터와 LiDAR 초기화를 확인합니다.

완료 체크리스트

  1. SBC가 Wi-Fi IP를 받고 PC에서 SSH 접속됩니다.
  2. ros2 --help가 정상 출력됩니다.
  3. PC와 SBC의 ROS_DOMAIN_ID가 같습니다.
  4. 모델과 LDS 환경변수가 실제 하드웨어와 일치합니다.
  5. ros2 launch turtlebot3_bringup robot.launch.py가 오류 없이 실행됩니다.
  6. PC에서 로봇 토픽이 보이고 teleop 명령에 반응합니다.

안전: 첫 모터 시험은 바퀴를 바닥에서 들어 올린 상태로 진행합니다.
