YOLO

You Only Look Once

YOLO는 한 번의 추론으로 이미지 안의 여러 객체를 분류하고 위치를 bounding box로 찾는 객체 탐지 모델입니다.

Camera frame (BGR)
        ↓
YOLO11n predict(imgsz, conf)
        ↓
class + confidence + xyxy box
        ↓
text result / annotated image / realtime loop
  • class: 어떤 물체인지 나타내는 번호와 이름
  • confidence: 예측 신뢰도
  • xyxy: 왼쪽 위와 오른쪽 아래의 box 좌표

02

PinkyPro Camera 사용

from ultralytics import YOLO
from PIL import Image
from IPython.display import display, clear_output
import time, io, os
from pinkylib import Camera

def capture_one_frame(cam):
    frame_bgr = cam.get_frame()
    image_rgb = Image.fromarray(frame_bgr[:, :, ::-1])
    return frame_bgr, image_rgb

Camera.get_frame()은 BGR 배열을 반환합니다. OpenCV·YOLO에는 원본 BGR을 쓰고, Pillow/Jupyter 표시에는 channel을 뒤집어 RGB로 변환합니다.

def test_camera_once():
    cam = Camera()
    cam.start()
    try:
        frame_bgr, image_rgb = capture_one_frame(cam)
        display(image_rgb)
        return frame_bgr
    finally:
        cam.close()
03

YOLO11n model과 한 장 추론

model = YOLO("yolo11n.pt")
print("Model loaded:", model.model_name)

def detect_once_from_camera(imgsz=640, conf=0.25):
    cam = Camera()
    cam.start()
    try:
        frame_bgr, image_rgb = capture_one_frame(cam)
        display(image_rgb)

        results = model.predict(
            source=frame_bgr,
            imgsz=imgsz,
            conf=conf,
            verbose=False,
        )
        annotated_bgr = results[0].plot()
        annotated_rgb = Image.fromarray(annotated_bgr[:, :, ::-1])
        display(annotated_rgb)
        return results[0], annotated_bgr
    finally:
        cam.close()
첫 실행: yolo11n.pt가 없으면 자동 다운로드하므로 Internet 연결과 저장 공간이 필요합니다. 이후에는 local model file을 재사용합니다.
04

탐지 결과 읽기

def print_detection_result(result):
    if result.boxes is None or len(result.boxes) == 0:
        print("탐지된 물체가 없습니다.")
        return

    for i, box in enumerate(result.boxes, start=1):
        cls_id = int(box.cls[0])
        name = model.names[cls_id]
        conf = float(box.conf[0])
        x1, y1, x2, y2 = [float(v) for v in box.xyxy[0]]
        print(f"{i}. {name} / confidence={conf:.2f} "
              f"/ box=({x1:.0f}, {y1:.0f}, {x2:.0f}, {y2:.0f})")

result.boxes가 없거나 길이가 0인 경우를 먼저 처리해야 빈 탐지 결과에서도 오류가 나지 않습니다.

05

짧은 실시간 탐지와 성능 조절

def run_short_realtime_detection(
        num_frames=30, imgsz=320, conf=0.25, delay=0.03):
    cam = Camera()
    cam.start()
    try:
        for i in range(num_frames):
            frame_bgr, _ = capture_one_frame(cam)
            result = model.predict(
                source=frame_bgr, imgsz=imgsz,
                conf=conf, verbose=False)[0]
            annotated_bgr = result.plot()
            annotated_rgb = Image.fromarray(annotated_bgr[:, :, ::-1])
            clear_output(wait=True)
            print(f"frame {i + 1}/{num_frames} | imgsz={imgsz}")
            display(annotated_rgb)
            time.sleep(delay)
    finally:
        cam.close()

imgsz를 640 → 480 → 320으로 줄이면 Raspberry Pi에서 추론이 빨라질 수 있지만 작은 물체를 놓칠 가능성이 커집니다. 같은 frame을 사용해 time.perf_counter()로 시간을 비교해야 공정합니다.

for size in [320, 480, 640]:
    t0 = time.perf_counter()
    result = model.predict(source=frame_bgr,
                           imgsz=size, conf=0.25,
                           verbose=False)[0]
    elapsed = time.perf_counter() - t0
    fps = 1 / elapsed if elapsed > 0 else 0
    print(size, elapsed, fps)

07

카메라·모델 운영 주의

  • 모든 카메라 함수에 try/finally를 사용해 예외가 나도 cam.close()를 실행합니다.
  • 카메라가 이미 사용 중이면 중복 instance를 만들지 않고 이전 process를 종료합니다.
  • 신뢰도가 낮은 결과를 로봇 행동으로 바로 연결하지 않습니다.
  • 탐지 class allowlist, confidence threshold, 연속 frame 확인을 거친 뒤 행동합니다.
  • 촬영·저장 이미지에 사람이나 민감 정보가 포함될 수 있으므로 보관·공유 범위를 제한합니다.
  • CPU 온도와 memory 사용량을 확인하고 장시간 loop에는 종료 조건을 둡니다.
08

문제 해결

  • ModuleNotFoundError: Notebook의 sys.executable과 package 설치 Python 확인
  • Camera frame 없음: camera cable·권한·다른 사용 process 확인
  • 색상이 이상함: BGR↔RGB 변환이 한 번만 적용됐는지 확인
  • Model 다운로드 실패: Internet·DNS·저장 공간 확인 또는 model file 직접 배치
  • 탐지가 너무 느림: imgsz=320, frame 수·표시 빈도 감소
  • 작은 물체를 놓침: 조명·거리 개선, imgsz 증가, confidence 조정
  • 카메라 재실행 실패: 모든 경로에서 cam.close()가 호출됐는지 확인
