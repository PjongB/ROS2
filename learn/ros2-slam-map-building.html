03.10 · ROS 2 JAZZY

SLAM 지도 작성

SLAM Toolbox의 구조와 파라미터를 이해하고, Pinky Pro를 주행시켜 실제 네비게이션에 사용할 지도를 생성·저장하는 실습입니다.

01

SLAM의 기본 구조

원본: SLAM

  • SLAM은 로봇의 위치를 추정하면서 주변 환경의 지도를 동시에 작성합니다.
  • Front-end는 센서 데이터와 스캔을 매칭하고, back-end는 전체 위치 그래프의 오차를 최적화합니다.
  • Loop closure는 이전에 방문한 장소를 인식해 누적된 오차를 줄입니다.
02

SLAM Toolbox가 하는 일

원본: SLAM Toolbox 기능

  • LaserScan과 odometry·TF를 사용해 2D occupancy grid map을 만듭니다.
  • online_sync_launch.py는 실시간 스캔을 순서대로 처리하는 매핑 노드를 실행합니다.
  • 필요한 주요 입력은 /scan과 odom → base_footprint TF입니다.
03

map_building.launch.xml

원본: Launch 구성

  • slam_params_file은 pinky_navigation/params/mapper_params.yaml을 기본값으로 사용합니다.
  • 실제 로봇은 use_sim_time:=false, Gazebo는 use_sim_time:=true로 시간 기준을 맞춥니다.
  • Launch 파일은 SLAM Toolbox의 online sync launch를 include하고 설정 파일과 시간 옵션을 전달합니다.
04

mapper_params.yaml 핵심 설정

원본: TF·topic·해상도·스캔 매책

  • map_frame: map, odom_frame: odom, base_frame: base_footprint, scan_topic: /scan을 로봇 구성과 일치시킵니다.
  • resolution: 0.05는 지도 한 셀을 5cm로 사용하고, max_laser_range: 10.0은 매핑에 사용할 LiDAR 범위를 정합니다.
  • 최소 이동 거리·각도, scan buffer, loop closure 검색 범위와 응답 임계값으로 속도와 정확도를 조절합니다.
05

Gazebo에서 지도 만들기

원본: 실제 지도 만들기

  • Gazebo 시뮬레이션을 실행한 뒤 SLAM과 RViz2를 시작합니다.
  • RViz에서 Map·LaserScan·TF를 확인하고, 키보드로 로봇을 천천히 조작하며 공간을 중복 탐색합니다.
  • 지도가 틀어지면 /scan, TF 연결, odometry, 시간 설정과 loop closure 성공 여부를 확인합니다.
06

생성한 지도 저장

원본: 지도 저장·맵 파일

  • Nav2 map saver CLI로 occupancy grid를 이미지와 YAML 설정 파일로 저장합니다.
  • YAML의 image, resolution, origin, 점유·비점유 임계값을 확인합니다.
  • 도면이나 기존 그림을 사용할 때도 맵 이미지와 YAML의 좌표·해상도를 맞춰야 합니다.

핵심 실행 명령

source /opt/ros/jazzy/setup.bash
source ~/pinky/install/setup.bash

# Gazebo 시뮬레이션
ros2 launch pinky_gz_sim launch_sim.launch.xml

# Gazebo 시간을 사용하는 SLAM
ros2 launch pinky_navigation gz_map_building.launch.xml

# RViz에서 지도 확인
ros2 launch pinky_navigation map_building.launch.xml use_sim_time:=true

# 키보드 주행
ros2 run teleop_twist_keyboard teleop_twist_keyboard

# 지도 저장
ros2 run nav2_map_server map_saver_cli -f ~/pinky_map
