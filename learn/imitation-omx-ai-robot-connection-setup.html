로봇 연결 세팅 - OMX-AI

Leader와 Follower의 전원·USB를 올바르게 연결하고, Linux 권한과 udev 규칙을 설정해 재부팅하거나 연결 순서가 바뀌어도 같은 장치 이름을 사용합니다.

강의 PDF전체 실행 순서 ↓
목차하드웨어 연결LED 확인포트 찾기장치 권한장치 정보udev 규칙적용·검증전체 순서문제 해결
이번 강의의 핵심/dev/ttyACM0 같은 번호는 연결 순서에 따라 바뀔 수 있습니다. 장치의 고유 serial을 기준으로 /dev/omx_leader와 /dev/omx_follower라는 고정 별칭을 만듭니다.
00

Leader·Follower 하드웨어 연결

먼저 고정: 두 로봇을 작업대에 단단히 고정하고 팔이 움직일 공간을 확보하세요. Follower는 토크가 크므로 손·케이블·도구를 가동 범위 밖에 둡니다.
구분역할USB외부 전원고정 장치명
Leader사용자 시연 입력전원 + 통신불필요/dev/omx_leader
Follower동작 실행통신12V 5A 필요/dev/omx_follower
  1. USB-C를 각 Bus Servo Adapter(OpenRB-150)에 연결합니다.
  2. USB-A를 PC에 연결합니다.
  3. Follower에 12V 5A 어댑터를 연결합니다.
01

어댑터 LED 확인

LED색상의미확인할 점
PWR빨강전원 공급꺼져 있으면 USB·외부 전원 확인
DXL초록서보 통신 활성명령 중 반응이 없으면 케이블·모터 bus 확인
USER주황사용자 상태 표시실습 프로그램의 상태 정의에 따라 해석
02

현재 serial 포트 찾기

LeRobot 환경을 활성화한 뒤 포트 검색 도구를 실행합니다. 안내가 나오면 확인할 로봇의 USB를 뽑고 Enter를 눌러 사라진 장치를 찾습니다.

source ~/venv/il/bin/activate
lerobot-find-port
번호를 이름처럼 외우지 마세요. 오늘의 Leader가 ttyACM0이어도 다음 부팅에는 ttyACM1이 될 수 있습니다. 이 값은 udev 설정 전 장치를 식별할 때만 사용합니다.
03

장치 접근 권한

임시 진단용

sudo chmod 666 /dev/ttyACM0
sudo chmod 666 /dev/ttyACM1

chmod 666은 모든 사용자에게 읽기·쓰기를 열며 재연결하면 사라집니다. 첫 연결의 권한 문제를 진단할 때만 사용하세요.

권장: dialout 그룹 등록

sudo usermod -a -G dialout $USER
sudo reboot now
재부팅 전: 열려 있는 작업을 저장하세요. 재부팅 대신 로그아웃 후 다시 로그인해도 그룹 변경이 적용됩니다.
groups

출력에 dialout이 있으면 지속적인 serial 장치 접근 권한이 적용된 것입니다.

04

각 장치의 고유 정보 조회

Leader와 Follower를 하나씩 확실히 구분해 아래 명령을 실행하고 ID_VENDOR_ID와 ID_SERIAL_SHORT를 기록합니다.

udevadm info -q all -n /dev/ttyACM0 | egrep 'DEVNAME=|ID_VENDOR_ID=|ID_MODEL_ID=|ID_SERIAL=|ID_SERIAL_SHORT=|ID_MODEL=|ID_VENDOR=|ID_USB_INTERFACE_NUM='

udevadm info -q all -n /dev/ttyACM1 | egrep 'DEVNAME=|ID_VENDOR_ID=|ID_MODEL_ID=|ID_SERIAL=|ID_SERIAL_SHORT=|ID_MODEL=|ID_VENDOR=|ID_USB_INTERFACE_NUM='
항목용도규칙에서 사용
ID_VENDOR_IDUSB 제조사 IDATTRS{idVendor}
ID_SERIAL_SHORT보드별 고유 serialATTRS{serial}
DEVNAME현재 임시 포트확인용
05

고정 장치명 udev 규칙 작성

sudoedit /etc/udev/rules.d/99-omx.rules

아래 꺾쇠 부분을 방금 조회한 실제 값으로 바꿉니다. PDF에 보이는 예시 serial은 강의 장비의 값이므로 그대로 복사하면 안 됩니다.

SUBSYSTEM=="tty", ATTRS{idVendor}=="<VENDOR_ID>", ATTRS{serial}=="<FOLLOWER_SERIAL>", SYMLINK+="omx_follower"
SUBSYSTEM=="tty", ATTRS{idVendor}=="<VENDOR_ID>", ATTRS{serial}=="<LEADER_SERIAL>", SYMLINK+="omx_leader"
매핑 확인: Follower의 serial이 omx_follower, Leader의 serial이 omx_leader 행에 들어갔는지 저장 전에 다시 확인하세요.
06

규칙 적용과 검증

sudo udevadm control --reload-rules
sudo udevadm trigger

두 USB 케이블을 분리했다가 다시 연결한 후 고정 별칭과 실제 연결 대상을 확인합니다.

ls -l /dev/omx_follower /dev/omx_leader
readlink -f /dev/omx_follower
readlink -f /dev/omx_leader

ls -l에는 udev가 만든 symbolic link가, readlink -f에는 현재 연결된 /dev/ttyACM* 경로가 표시됩니다. USB 연결 순서를 바꿔도 별칭의 로봇 역할은 같아야 합니다.

터미널에 입력하는 전체 순서

# 1. 포트 식별
source ~/venv/il/bin/activate
lerobot-find-port

# 2. 영구 권한 부여 (적용하려면 재로그인 또는 재부팅)
sudo usermod -a -G dialout $USER
sudo reboot now

# 3. 재접속 후 그룹·장치 정보 확인
groups
udevadm info -q all -n /dev/ttyACM0 | egrep 'DEVNAME=|ID_VENDOR_ID=|ID_SERIAL_SHORT='
udevadm info -q all -n /dev/ttyACM1 | egrep 'DEVNAME=|ID_VENDOR_ID=|ID_SERIAL_SHORT='

# 4. 실제 조회값으로 udev 규칙 작성
sudoedit /etc/udev/rules.d/99-omx.rules

# 5. 규칙을 다시 읽고, USB 재연결 후 검증
sudo udevadm control --reload-rules
sudo udevadm trigger
ls -l /dev/omx_follower /dev/omx_leader
readlink -f /dev/omx_follower
readlink -f /dev/omx_leader

완료 체크리스트

  1. 두 로봇을 고정하고 Leader USB, Follower USB·12V 5A를 구분했습니다.
  2. LED와 lerobot-find-port로 연결을 확인했습니다.
  3. 사용자를 dialout 그룹에 등록했습니다.
  4. 각 보드의 실제 vendor ID와 serial을 기록했습니다.
  5. udev 규칙으로 역할별 고정 별칭을 만들었습니다.
