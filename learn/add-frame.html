새 TF 축과 궤적 추가하기

기존 child_frame을 유지하면서 child_frame_2를 TF 트리에 추가하고, RViz에서 두 번째 이동 궤적을 확인합니다.

예상 30분TF 추가 → Marker 복제 → RViz 검증ROS 2 Jazzy

먼저 TF 트리를 설계한다

새 축은 기존 축과 이름이 달라야 하며 부모 프레임을 명확히 정해야 합니다. 이번 실습에서는 두 자식이 모두 moving_frame을 부모로 사용합니다.

world └── moving_frame ├── child_frame └── child_frame_2
같은 부모 아래 형제 프레임으로 추가하면 두 프레임의 움직임을 쉽게 비교할 수 있습니다.

combined_frame.py에 새 축 추가

timer_callback() 안에서 기존 child_frame을 발행하는 코드 바로 아래에 추가합니다.

# moving_frame -> child_frame_2
angle2 = -1.5 * self.t
x3 = 1.5 * math.cos(angle2)
y3 = 1.5 * math.sin(angle2)
yaw3 = math.atan2(-y3, -x3)

self.send_tf(
    'moving_frame',
    'child_frame_2',
    x3, y3, 0.0, yaw3
)
기존 child_frame반지름 1.0 m, 정방향 2배 속도
새 child_frame_2반지름 1.5 m, 역방향 1.5배 속도

두 번째 Marker 노드 만들기

frame_trail_publisher_marker_2.py를 복사해 frame_trail_publisher_marker_3.py를 만든 뒤 아래 항목을 변경합니다.

대상 프레임과 노드 이름

super().__init__('frame_trail_publisher_2')
self.target_frame = 'child_frame_2'

별도 Marker 토픽

self.marker_pub = self.create_publisher(
    Marker,
    'frame_trail_marker_2',
    10
)

구분하기 쉬운 파란색

marker.color.r = 0.2
marker.color.g = 0.5
marker.color.b = 1.0
marker.color.a = 0.8
두 Marker가 같은 토픽과 같은 namespace/id를 쓰면 서로 덮어쓸 수 있습니다. 별도 토픽을 쓰거나 Marker ID를 다르게 지정하세요.

setup.py에 실행 이름 등록

entry_points → console_scripts 목록에 새 실행 파일을 연결합니다.

'frame_trail_publisher_marker_3 = my_tf.frame_trail_publisher_marker_3:main',

등록을 바꾼 뒤에는 반드시 다시 빌드하고 현재 셸에 설치 환경을 적용합니다.

cd ~/dev_ws/my_tf_tutorials
colcon build --symlink-install --packages-select my_tf
source install/setup.bash

자주 발생하는 오류

target_frame does not exist

combined_frame을 먼저 실행했는지, 모든 터미널의 ROS_DOMAIN_ID가 같은지 확인합니다.

RViz Marker가 Status: Error

Error subscribing: Empty topic name이면 Marker 디스플레이의 Topic 행에 정확한 토픽을 선택합니다.
