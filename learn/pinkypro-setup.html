PinkyPro 환경 설정

안전 먼저첫 bringup 전에는 로봇 바퀴를 바닥에서 들어 올리고, PC와 로봇의 ROS_DOMAIN_ID가 같은지 확인하세요.
01

로봇용 SD 카드 준비

원본: Pinky 환경 설정

  • 제공된 이미지를 내려받고 Raspberry Pi Imager를 설치합니다.
  • Raspberry Pi 5와 Use custom을 선택한 뒤 이미지를 SD 카드에 기록합니다.
  • 대상 저장장치를 다시 확인한 뒤 포맷·flashing을 진행합니다.
02

PC 워크스페이스 구성

패키지 clone·의존성·빌드

  • ~/pinky_/src에 PinkyPro 패키지를 clone합니다.
  • rosdep으로 의존성을 설치하고 colcon build로 빌드합니다.
  • 새 터미널마다 설치 공간의 setup 파일을 source합니다.
03

네트워크와 SSH

로봇 AP 접속·Wi-Fi 설정

  • PC를 Pinky 네트워크에 연결한 뒤 ssh pinky@192.168.4.1로 접속합니다.
  • nmcli device wifi list로 연결 가능한 네트워크를 확인합니다.
  • Wi-Fi 설정 후 ping으로 인터넷 연결을 검증합니다.
04

VS Code Remote SSH

원격 개발 환경

  • Microsoft Remote - SSH 확장을 설치합니다.
  • 호스트에 pinky@192.168.4.1을 입력하고 Linux를 선택합니다.
  • 로봇의 작업 폴더를 열어 파일을 확인하고 편집합니다.
05

ROS 2로 첫 주행

bringup·topic·teleop

  • PC와 로봇의 ROS_DOMAIN_ID를 같은 값으로 설정합니다.
  • 로봇에서 bringup을 실행하고 PC의 ros2 topic list로 연결을 확인합니다.
  • teleop_twist_keyboard로 저속 주행하며 방향과 정지 동작을 검증합니다.

핵심 실행 명령

mkdir -p ~/pinky_/src
cd ~/pinky_/src
git clone https://github.com/pinklab-art/pinky_pro.git
sudo rosdep init
rosdep update
cd ~/pinky_
rosdep install --from-paths src --ignore-src -r -y
colcon build
source ~/pinky_/install/local_setup.bash

# 로봇 접속과 첫 주행
ssh pinky@192.168.4.1
ros2 launch pinky_bringup bringup_robot.launch.xml
ros2 run teleop_twist_keyboard teleop_twist_keyboard
