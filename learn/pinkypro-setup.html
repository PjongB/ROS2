MAP

설정 전체 흐름

로봇 준비와 PC 준비를 병렬로 진행

로봇: 이미지 → SD Flash → 부팅 → Wi-Fi → SSH
                                         ↓
PC: workspace → git clone → rosdep → build → ROS_DOMAIN_ID
                                         ↓
                       topic 확인 → bringup → teleop
SAFE

실습 전 안전 원칙

첫 bringup 전에 확인

  • 처음 모터를 활성화할 때는 바퀴를 바닥에서 들어 올립니다.
  • 로봇 주변의 낙하 구간, 케이블과 장애물을 제거합니다.
  • teleop 정지 키와 전원 차단 방법을 미리 확인합니다.
  • SD 카드 대상 드라이브를 정확히 확인합니다.
01

로봇용 SD 카드 준비

원본: Pinky 환경 설정

  • 제공된 이미지를 내려받고 Raspberry Pi Imager를 설치합니다.
  • Raspberry Pi 5와 Use custom을 선택한 뒤 이미지를 SD 카드에 기록합니다.
  • 대상 저장장치를 다시 확인한 뒤 포맷·flashing을 진행합니다.
02

PC 워크스페이스 구성

패키지 clone·의존성·빌드

  • ~/pinky_/src에 PinkyPro 패키지를 clone합니다.
  • rosdep으로 의존성을 설치하고 colcon build로 빌드합니다.
  • 새 터미널마다 설치 공간의 setup 파일을 source합니다.
03

네트워크와 SSH

로봇 AP 접속·Wi-Fi 설정

  • PC를 Pinky 네트워크에 연결한 뒤 ssh pinky@192.168.4.1로 접속합니다.
  • nmcli device wifi list로 연결 가능한 네트워크를 확인합니다.
  • Wi-Fi 설정 후 ping으로 인터넷 연결을 검증합니다.
04

VS Code Remote SSH

원격 개발 환경

  • Microsoft Remote - SSH 확장을 설치합니다.
  • 호스트에 pinky@192.168.4.1을 입력하고 Linux를 선택합니다.
  • 로봇의 작업 폴더를 열어 파일을 확인하고 편집합니다.
05

ROS_DOMAIN_ID 맞추기

PC와 로봇의 DDS 통신 범위

export ROS_DOMAIN_ID=<수업에서 지정한 값>
echo $ROS_DOMAIN_ID
  • 값이 다르면 같은 네트워크에서도 서로의 노드와 토픽을 발견하지 못합니다.
  • ~/.bashrc에 저장했다면 새 터미널을 열거나 다시 source합니다.
  • 다른 팀과 값이 겹치면 의도하지 않은 로봇이 보일 수 있습니다.
06

ROS 2로 첫 주행

bringup·topic·teleop

  • 배터리 상태를 확인하고 바퀴를 들어 올린 뒤 bringup을 실행합니다.
  • PC의 ros2 topic list로 로봇 토픽이 보이는지 확인합니다.
  • teleop_twist_keyboard로 저속 주행하며 방향과 정지를 검증합니다.
07

증상별 확인 순서

연결 문제를 계층별로 분리

  • SSH 실패: PC Wi-Fi, 로봇 전원·부팅, IP, ping을 확인합니다.
  • 토픽이 안 보임: ROS setup, ROS_DOMAIN_ID, 방화벽과 네트워크를 확인합니다.
  • 패키지를 못 찾음: workspace 경로, 빌드 성공 여부와 install setup을 확인합니다.
  • 모터가 움직이지 않음: bringup 오류, 배터리, cmd_vel과 안전 정지를 확인합니다.

마지막 실행 순서

mkdir -p ~/pinky_/src
cd ~/pinky_/src
git clone https://github.com/pinklab-art/pinky_pro.git
sudo rosdep init
rosdep update
cd ~/pinky_
rosdep install --from-paths src --ignore-src -r -y
colcon build
source ~/pinky_/install/local_setup.bash

# 로봇 접속과 첫 주행
ssh pinky@192.168.4.1
ros2 launch pinky_bringup bringup_robot.launch.xml
ros2 run teleop_twist_keyboard teleop_twist_keyboard

실습 체크리스트

  1. SD 카드가 정상 부팅됩니다.
  2. PC에서 로봇 IP로 SSH 접속됩니다.
  3. rosdep과 colcon build가 오류 없이 끝납니다.
  4. 양쪽 ROS_DOMAIN_ID가 같습니다.
  5. PC에서 로봇 토픽을 볼 수 있습니다.
  6. 바퀴를 든 상태에서 주행 명령 방향을 검증했습니다.
