NumPy 배열과 OpenCV

이미지를 숫자 배열로 읽고 높이·너비·채널과 픽셀 연산의 관계를 이해합니다.

원본 강의강의 PDFIPYNB 다운로드
이 페이지에서핵심 개념이론과 수식행렬로 보기함수·용어 정리실습 흐름확인할 점
한 줄 정리그레이 영상은 하나의 행렬, 컬러 영상은 채널 행렬 세 장을 쌓은 3차원 텐서입니다. NumPy 슬라이싱으로 특정 채널이나 관심 영역을 한 번에 읽고 바꿀 수 있습니다.

핵심 개념

픽셀영상 좌표 (x, y)에 저장된 밝기 또는 색 값
shape그레이는 (H, W), 컬러는 (H, W, C) 구조
채널RGB/BGR 색 성분을 분리해 담는 2차원 레이어
dtypeuint8은 0~255 범위를 갖는 대표적인 영상 자료형

이론과 수식

그레이 영상은 하나의 행렬, 컬러 영상은 채널 행렬 세 장을 쌓은 3차원 텐서입니다. NumPy 슬라이싱으로 특정 채널이나 관심 영역을 한 번에 읽고 바꿀 수 있습니다.

gray[y, x] → 밝기 1개 color[y, x] → [R, G, B] 또는 [B, G, R] shape = (height, width, channels)

행렬로 보기

R00R01…R10R11…⋮⋮Rhw
R 채널 행렬 - G와 B도 같은 크기

함수·용어 정리

함수·표현역할
img[y, x]한 픽셀 읽기
img[:, :, 0]첫 번째 채널 전체
img[y1:y2, x1:x2]ROI 영역
img[:, :, 1] = 0두 번째 채널 제거

실습 흐름

이미지 읽기shape·dtype 확인채널 분리배열 연산·표시

실습 전후 확인할 점

  • 행 인덱스 y가 높이, 열 인덱스 x가 너비임을 구분
  • uint8에서 255를 넘는 연산의 overflow 주의
  • Matplotlib의 RGB와 OpenCV의 BGR 순서 확인

세부 코드와 실행 예제는 위의 IPYNB 파일에서 셀 단위로 실습할 수 있습니다.
