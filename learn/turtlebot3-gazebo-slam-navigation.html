Gazebo SLAM & Navigation

Gazebo 월드에서 Cartographer로 지도를 만들고 저장한 뒤, 같은 지도에서 AMCL 위치 추정과 Nav2 목표·Waypoint 주행을 실습합니다.

01

SLAM과 Navigation의 역할

  • SLAM: 지도가 없을 때 LiDAR와 odometry로 지도를 작성합니다.
  • Map Saver: occupancy grid를 .pgm과 .yaml로 저장합니다.
  • AMCL: 저장된 지도와 현재 scan을 비교해 로봇 위치를 추정합니다.
  • Nav2: 전역·지역 경로와 속도 명령을 계산합니다.
  • use_sim_time:=True는 Gazebo의 /clock을 사용한다는 뜻입니다.
02

시작 전 환경 확인

source /opt/ros/jazzy/setup.bash
source ~/turtlebot3_ws/install/setup.bash
export TURTLEBOT3_MODEL=burger
echo $TURTLEBOT3_MODEL
ros2 pkg prefix turtlebot3_gazebo
ros2 pkg prefix turtlebot3_cartographer
ros2 pkg prefix turtlebot3_navigation2
이전 Gazebo가 남았을 때: 먼저 정상 종료합니다. 그래도 프로세스가 남을 때만 다른 Gazebo 작업이 없는지 확인하고 sudo pkill -9 -f "gz|gazebo|ign"을 사용합니다.
03

Cartographer로 지도 작성

  • Gazebo 월드를 완전히 띄운 뒤 Cartographer를 시작합니다.
  • teleop에서 w/a/s/d/x로 천천히 이동합니다.
  • 벽을 반복 관찰하고 처음 위치 부근으로 돌아오면 loop closure에 도움이 됩니다.
  • 급회전과 충돌은 odometry 오차를 키워 벽이 겹치거나 휘게 만듭니다.
04

지도 저장과 파일 확인

ros2 run nav2_map_server map_saver_cli -f ~/turtlemap
ls -lh ~/turtlemap.pgm ~/turtlemap.yaml
sed -n '1,20p' ~/turtlemap.yaml

PGM과 YAML 두 파일을 확인한 뒤 SLAM·teleop·Gazebo 터미널을 종료합니다.

05

AMCL 초기 위치와 Nav2 Goal

  1. 같은 Gazebo 월드를 다시 실행합니다.
  2. 저장한 YAML을 지정해 Navigation을 실행합니다.
  3. RViz의 2D Pose Estimate로 로봇 위치와 방향을 맞춥니다.
  4. LiDAR scan과 지도 벽이 겹치는지 확인합니다.
  5. Nav2 Goal로 목적지와 도착 방향을 지정합니다.
06

현재 위치·클릭 좌표·Waypoint

ros2 topic echo /amcl_pose
ros2 topic echo /clicked_point
  • /amcl_pose는 추정 위치와 covariance를 제공합니다.
  • Publish Point로 클릭하면 /clicked_point에서 map 좌표를 읽습니다.
  • Waypoint 모드에서 여러 목표를 추가한 뒤 Start Waypoint Following을 누릅니다.

터미널에 입력하는 전체 순서

2 · 지도 저장

# 터미널 D

3 · Navigation 터미널 2개

# 터미널 A - 같은 월드 다시 실행

# 터미널 B - 저장 지도 기반 Nav2
ros2 launch turtlebot3_navigation2 navigation2.launch.py \
  use_sim_time:=True map:=$HOME/turtlemap.yaml
FIX

문제 해결

  • 패키지를 못 찾음: ROS와 workspace setup을 source하고 빌드를 확인합니다.
  • RViz가 멈춤: ros2 topic echo /clock으로 시뮬레이션 시간을 봅니다.
  • 지도가 안 생김: /scan, /odom, TF를 확인합니다.
  • 지도를 못 읽음: $HOME/turtlemap.yaml처럼 절대경로를 씁니다.
  • 경로가 안 생김: 초기 위치 재설정 → scan 정합 → costmap 순서로 확인합니다.
✓

완료 체크리스트

  • Gazebo에서 /scan과 /odom이 발행됩니다.
  • 지도 PGM·YAML을 모두 저장했습니다.
  • AMCL scan과 지도 벽이 일치합니다.
  • Nav2 Goal에 도착하고 Waypoint를 순서대로 방문합니다.
