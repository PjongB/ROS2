Gazebo SLAM & Navigation

Gazebo 월드에서 Cartographer로 지도를 만들고 저장한 뒤, Nav2로 목표점과 여러 Waypoint를 주행합니다.

한 줄 정리같은 Gazebo 월드를 기준으로 SLAM 지도를 저장한 뒤, 그 YAML 지도를 Nav2에 넘겨 자율주행합니다.
MAP

실습 흐름

Gazebo world → Cartographer → teleop 탐색 → map 저장
                                          ↓
저장한 map.yaml → Nav2 → 2D Pose Estimate → Nav2 Goal
01

SLAM 지도 작성

  • Gazebo 월드를 먼저 실행합니다.
  • Cartographer SLAM과 teleop을 각각 새 터미널에서 실행합니다.
  • 벽 가까이까지 빠짐없이 탐색하되 급회전과 충돌을 피합니다.
02

지도 저장

지도 저장 후 .pgm 이미지와 .yaml 메타데이터가 모두 생성됐는지 확인하고 기존 프로세스를 종료합니다.

03

Nav2 주행

  • 저장한 YAML 경로로 Navigation을 실행합니다.
  • RViz의 2D Pose Estimate로 실제 로봇 자세를 지도와 맞춥니다.
  • Nav2 Goal의 위치와 화살표 방향을 함께 지정합니다.
04

좌표와 Waypoint

/amcl_pose는 추정된 현재 위치, /clicked_point는 RViz에서 선택한 지도 좌표를 제공합니다. Waypoint 모드에서는 점을 순서대로 추가한 뒤 Following을 시작합니다.

핵심 명령

export TURTLEBOT3_MODEL=burger
ros2 launch turtlebot3_gazebo turtlebot3_world.launch.py
ros2 launch turtlebot3_cartographer cartographer.launch.py use_sim_time:=True
ros2 run turtlebot3_teleop teleop_keyboard
ros2 run nav2_map_server map_saver_cli -f ~/map

ros2 launch turtlebot3_navigation2 navigation2.launch.py \
  use_sim_time:=True map:=$HOME/map.yaml
ros2 topic echo /amcl_pose
ros2 topic echo /clicked_point
  1. 지도 파일 두 개가 저장됩니다.
  2. LiDAR 스캔과 지도가 겹칩니다.
  3. 목표 경로가 생성되고 로봇이 도착합니다.
